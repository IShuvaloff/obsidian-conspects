## API
Серверное прокси-api, расположено в папке `/server/api`, разбито по категориям (отгрузки, продукты, сотрудники и т.д.). Включает в себя файлы запросов к api-серверу, именованные по шаблону с указанием типа запроса:
```
/api
	/brigades
		create.post.ts
		index.get.ts
		update.post.ts
	/products
		index.get.ts
		types.get.ts
```

## Страницы
Система страниц стандартная, выстроена в виде дерева, расположена в папке `/pages`:
```
/pages
	index.vue
	/worksheets
		index.vue
		[slug].vue
```

Особенности страниц:
1. страница производственного листа `/pages/worksheets/[slug].vue` - открывается при переходе на одноименную страницу с передачей параметра *slug*. Если:
	* параметр числовой - загружается и открывается страница листа по **id**, равному *slug*;
	* параметр равен *new* - создается новый лист (см. утилиту `/utils/worksheets.ts => createWorksheet()`), открывается страница с доступными для ввода данными ==TODO: проверить, если данный адрес введен вручную сотрудником, который не имеет права для сохранения новых листов - он не должен вообще открываться!==;

## Промежуточное ПО для авторизации
Глобальный миддлвар по адресу `/middleware/auth.global.ts`. Включает в себя проверку доступности выбранного маршрута (страницы) текущему пользователю. Данные о пользователе и его правах тянутся из ==композабла `useAuth`== (см. далее). 
Схема:
1. если текущая страница существует, но не включена в список доступных для юзера, отображаем ошибку 403 (запрет доступа);
2. если текущей страницы не существует, отправляем юзера на страницу `error.vue` с ошибкой 404.

## Структура сайта
Схема сайта показана в лейауте в файле `/layouts/default.vue` и представляет собой:
1. контейнер во всю высоту родителя^[высота родительских компонентов не превышает высоту экрана: ![[Pasted image 20241219125608.png]]] `el-container`;
2. левая шторка для отображения пользователя и списка доступного меню (компонент `/components/layout/Aside.vue`):
	1. шапка для шторки - информация о текущем пользователе (авторизация) (компонент `/components/layout/AsideHeader.vue`);
	2. скроллбар `el-scrollbar` с вложенным в него доступным для пользователя меню (компонент `/components/layout/Menu.vue`), которое берется из ==композабла `useAuth`== (см. далее);
3. вложенный контейнер с глобальными элементами страницы:
	1. шапка с именем страницы и кнопкой возврата к родительскому элементу (компонент `/components/layout/PageHeader.vue`);
	2. тело страницы `el-main` со слотом для включения содержимого из папки `/pages`^[ранее внутри этого блока располагался скроллбар, но впоследствии он был перемещен внутрь компонентов на самих страницах, поэтому, вероятно, слот можно извлечь из контейнера, вложенного внутрь `el-main`].

## Компоненты 
Компоненты расположены в стандартной папке `/components`, разбиты по категориям "Base" (базовые, элементарные), "Common" (усложненные, но общие для нескольких мест), "Layout" (требующиеся для построения структуры сайта).
1. базовые блоки:
	* блок-контейнер `/base/Block.vue` - блок для мелкой информации внутри, чаще всего для инпутов, имеет бордер и шапку, встроенную в него (опционально), а также слот для содержимого. В настоящее время применяется в компоненте `/common/Worksheet.vue` для группировки полей ввода;
	* контейнер для ввода данных с подписью `/base/InputContainer.vue` - включает в себя лейбл для инпута и слот для размещения инпута;
	* поле ввода номера `/base/InputNum.vue` - поле для ввода номера с возможным префиксом, постфиксом и сразу подобранными настройками;
2. общие блоки:
	* панель управления `/common/ControlPanel.vue` - панель, включающая кнопки (с иконками и опциональными подписями) ОБНОВИТЬ, ДОБАВИТЬ, ИЗМЕНИТЬ, УДАЛИТЬ. Нажатие на кнопки инициирует одноименные события.
	* панель сохранения/отмены `/common/SavePanel.vue` - панель с кнопками СОХРАНИТЬ, ОТМЕНИТЬ. Инициируют по нажатию события *save* и *cancel*.
	* таблица отгрузок `/common/Shipments.vue` - таблица с отгрузками, которая используется в нескольких местах, например: на вкладке "Отгрузки" на странице производственного листа (страница `/pages/worksheets/[slug].vue`) + в качестве вложенной таблицы в списке производственных листов (страница `/pages/worksheets/index.vue`). ==TODO: создать общий компонент "список" = панель управления + таблица, использовать ее==;

## Композаблы
Расположены в папке `/composables`, включают в себя полезные фрагменты кода:
1. `useApi` - упрощающие утилиты для выполнения сложных запросов с обработкой ошибок и выполнением сопутствующих операций, например:
	* `useFetchDelete` - утилита для удаления одной или нескольких записей из таблицы. Включает параметры *path* (URL-адрес для [[#API|серверного API-запроса]]), *ids* (массив ключей подлежащих удалению объектов), *loader* (опциональный флаг лоадера, для отображения процесса загрузки во внешнем элементе), *labels* (опциональный объект текстовых сообщений для успешного, частичного и ошибочного выполнения запросов);
2. `useAuth` - авторизационное хранилище, содержащее информацию о пользователе, а также:
	* проверку ролей (должностей) - *isManager/isAdmin/isDirector*;
	* доступных страниц (*pages*);
	* информацию о разрешении на апдейт различных модулей *canUpdate...* (отгрузок, производственных листов, пользователей, бригад и т.д.);
3. `useHttp` - утилита для выполнения `$fetch`-запроса к [[#API|серверному API]] с возможностью подключения интерфейсов для выводимых данных;
4. `useMenu` - утилита для вывода общего списка меню (для фильтрации в `useAuth`) и функция формирования линейного списка (на случай, если параметр - список - содержит вложенные элементы);
5. композаблы-хранилища для хранения и выгрузки данных по *сотрудникам*, *бригадам*, *производственным листам*, *отгрузкам*, *продуктам* и т.д.^[внутри выгрузка данных из серверных запросов производится чаще всего в фоновом режиме синхронно (т.е. через `$fetch(...).then(res => ...)`), поэтому если требуется ожидание выполнения, следует переделывать запросы на асинхронные и вызывать извне уже с помощью `await`].

## Интерфейсы
Интерфейсы по всем сущностям содержатся в стандартной папке `/interfaces` в одноименных сущностям файлах.

## Утилиты
Располагаются в стандартной папке `/utils` и включают в себя утилиты:
1. для работы с датами и временем `dates.ts` (форматирование, вычисления и т.д.);
2. базовые `base.ts` - скроллы, запуски/отключения лоадеров, слипы и пр.;
3. математические `math.ts`, в частности округления;
4. текстовые `text.ts` - множественные формы существительных, вывод сообщения об ошибке по объекту ошибки и пр.;
5. числовые `nums.ts` - для обработки числовых данных, например, вывода локально отформатированных;
6. специальные:
	1. для работы с производственными листами `worksheets.ts`: создание нового листа, расчет статусов и пр.;
