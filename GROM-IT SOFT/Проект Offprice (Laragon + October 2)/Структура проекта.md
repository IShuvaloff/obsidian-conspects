В проекте все редактируемые файлы расположены в папке `themes`, внутри которых можно разместить несколько различных тем проекта. Главной темой в Offprice является - `banner`. Файл `.htm` проекта состоит из 3 частей:
1. *технические данные до блока php*;
2. блок PHP;
3. блок HTML (работает с шаблонизатором *Twig*).

## Конструктор
**Layout** - общий план страницы. Каждая страница в приложении привязана к определенному лейауту.
1. `layouts/banner_layout.htm` - основной файл, с которого формируется структура проекта. В блоке PHP вызываются функции при создании страницы:
	1. функция `onStart` - отрабатывает, когда проект запускается. Лучшее место для задания глобальных переменных проекта:
   
	   ![[Pasted image 20240305144817.png]]

2. Файл лейаута состоит из трех частей (см. выше) - html, php и еще один блок;
3. В блоке HTML подключаются различные ресурсы командами шаблонизатора, например:
	1. подключение html-кода с помощью команды `{% partial %}`, в данном случае тега `<head>` (шапки) со всеми *мета-тегами, линками и ссылками на скрипты*:
