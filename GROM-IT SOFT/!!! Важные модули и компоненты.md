
==Модули==:
1. `src/modules/gallery` - галерея-слайдер с настраиваемым `object-fit` по параметру:
	1. простейший слайдер с минимальным набором опций, который можно расширять при необходимости дополнительными параметрами;
	2. идеально подходит для создания модальной галереи;
	3. *располагается в проекте "TDS Group"*;
2. `src/modules/resize` - компонент изображения, которое автоматически кропится через сервер **imgProxy**. Принцип работы сервиса таков:  и сохраняется на сервере, отдавая новый URL. В дальнейшем при обращении с тем же запросом к серверу мы просто получаем URL ранее созданной картинки:
	1. для работы с этим сервисом нужен развернутый сервер для текущего приложения, как, например, https://img.oootds.group/). **Принцип работы сервиса imgProxy**:
		1. при первом запросе на сервер с передачей на него исходного URL изображения там формируется новая картинка нужного размера;
		2. скропленная картинка сохраняется на сервере;
		3. сервер возвращает новый URL созданного изображения;
		4. в дальнейшем при обращении с тем же запросом к серверу мы просто получаем URL ранее созданной картинки;
	2. требуется доработка - добавить компонент `<picture>`, внутри которого будет развернуто несколько URL в зависимости от текущей ширины экрана (см. компонент `src/components/base/Image.vue`);
	3. *располагается в проекте "TDS Group"*;

==Компоненты==:
1. `XScrollBlock` - прокручиваемый по горизонтали блок, у которого скролл включается в случае превышения суммарной ширины содержимого ширине контейнера, содержащего данный блок:
	1. идеально подходит для линейки изображений, которую требуется представить в виде простейшего слайдера;
	2. позволяет настроить выравнивание элементов внутри при перелистывании (с левого края, правого края и по центру);
	3. позволяет задать кастомное позиционирование элементов внутри путем присвоения классов элементу блока (например, сетка грид при превышении определенного размера экрана);
	4. подробности см. в [[Настройки скролла контейнера|настройках скролла контейнеров]];
2. `Share` - компонент "**Поделиться**" в социальных сетях::
	1. требует установки библиотеки Яндекса "Поделиться" `ya-share2`:
	2. подробности работы см. в компоненте `src/components/common/Share`;
	3. *располагается в проекте "Завидово"*;
3. `Map` - карта Яндекс со всеми требуемыми настройками:
	1. требует подключения библиотеки Яндекса `vue-yandex-maps` (прослойка между стандартным API Яндекса и приложением Vue);
	2. подробности работы см. в компоненте `src/components/UI/Map`;
	3. *располагается в проекте "TDS Group"*;
4. `RequestForm` - форма для ввода данных и отправки их POST-запросом на сервер:
	1. содержит переменные с данными в полях, их возможными ошибками, функции валидации введенных данных до отправки на сервер, обработку ошибок при отправке, а также обработку результата запроса, в т.ч. возможных его ошибок;
	2. содержит маску ввода телефонного номера для полей с типом `<input type="tel"/>` (см. компонент `src/components/base/Input.vue`);
	3. **подключена каптча** из плагина `vue3-smart-captcha`, получение токена которой производится в функции `getCaptchaToken` из директории `src/services/api.ts`. Подробности по установке каптчи смотри [[|здесь]]
	4. *располагается в проекте "TDS Group*, в модуле `src/modules/requests/components`;

5. `VideoFrame` - компонент, возвращающий `<iframe />`-код для воспроизведения видео из YouTube и RuTube:
