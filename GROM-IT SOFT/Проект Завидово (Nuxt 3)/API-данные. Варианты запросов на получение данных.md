1. Прямое обращение асинхронным запросом к [[API базы данных (админка)|API-маршруту]] БД. Используется ==композабл **`useHttp`**==, расположенная по адресу `src/composables/useHttp` (см. на примере модуля `src/modules/chem-zanyatsya/services/service.ts -> reloadActivities`):

	![[Pasted image 20231115105420.png]]

	* функция `useHttp<ApiResponseList>` возвращает объект с интерфейсом `ApiResponseList`;
	* интерфейс `ApiResponseList<IDutyCardResponse[]>` возвращает в качестве поля `data` массив объектов интерфейса `IDutyCardResponse`;
	* первым параметром указывается код API-маршрута;
	* вторым параметром указываются параметры выполнения запроса (см. в админке для указанного маршрута);
	* возврат данных из функций, внутри которых вызывается `useHttp`, следует рассмотреть отдельно [[API-запросы. Обработка полученных данных|здесь]];

2. Расширение функционала `useHttp` - обращение асинхронным запросом с целью извлечения целой страницы данных (подходит для сложных страниц с большим количеством смешанных блоков из разных разделов) - используется ==компазабл **`usePageStore`**== из папки `src/store/pages`:

	![[Pasted image 20231115110910.png]]
	![[Pasted image 20231115110936.png]]
	![[Pasted image 20231115110552.png|500]]

	* в первую очередь идет проверка уже открывавшейся ранее страницы с той целью, чтобы не перезагружать ее заново, для этого мы и обращаемся к `store` из блока со страницами. Загрузка начинается только в случае отсутствия таковой в хранилище. Функция получения страницы из хранилища *`getPageByCode`*:

		```ts
		const page = await usePageStore().getPageByCode("partneram");
		```

	* идет обращение к `useHttp` по блоку страницы с указанием кода конкретной страницы: `/page/{code}` (см. [[API базы данных (админка)#^1a15a2|API страницы сайта в админке]], блок "Страницы");
	* функция возвращает (см. порядок работы `useHttp` в пред. пункте) в конце объект с интерфейсом `Page`, который представляет собой либо пустышку, либо объект интерфейса `HomePage` с баннером, контентом и заголовком;
	* ВАЖНОЕ: данные по целым страницам можно заполнять/редактировать вручную через интерфейс [[API базы данных (админка)|админки]] (cм. блоки с настройками страниц)!
	* тип возвращаемых данных - `Page`, который может быть либо равен `null`, либо типу данных `HomePage`. В свою очередь `HomePage` представляет собой интерфейс:
	  
		  ![[Pasted image 20231127101032.png|400]]
		  
	* в свою очередь баннер (верхняя часть страницы) представляет собой тип данных `DynamicHero` (информацию по баннеру см. в п.3 далее);
3. Извлечение данных по одной из частей страницы, а именно баннеру. Используется ==композабл **`useHeroStore`**==. Расположен по адресу `src/modules/dynamic-hero/store.ts`. Принцип работы аналогичен:
	* идет обращение к хранилищу баннеров с той целью, чтобы не перезагружать одну и ту же информацию несколько раз;
	* если такой баннер еще не загружался, идет обращение к `useHttp` по API-адресу `/banner/{code}` (см. [[API базы данных (админка)#^1a15a2|API страницы сайта в админке]]);
	* тип возвращаемых данных - `DynamicHero`:

		  ![[Pasted image 20231127101214.png|270]]

	* баннер также содержится в результате получения данных о странице (см. п.2 ранее) в поле `banner`; 
	* *данные по баннеру будут выводиться только в том случае, если в баннере имеется хотя бы один активный слайд*.
