#useDayjs #useHttp 

О композаблах можно посмотреть [[Композаблы Nuxt.js (composables)|здесь]]. 

В проекте композаблы располагаются в папке `src/composables`:
1. **`useDayjs`** - композабл, который использует плагин Day.js для обработки дат и времени, а также их интернационализации. В данном случае композабл выполняет 2 действия:
	* выставляет русскую локализацию (для работы метода `.locale` требуется *импортировать в модуль, где выставляется локализация, соответствующий файл локализации* - `import "dayjs/locale/ru";`)
	* возвращает объект `dayjs` с русской локализацией для последующего использования:
		```ts
		import "dayjs/locale/ru";
		
		export const useDayjs = () => {
			dayjs.locale("ru");
			return dayjs;
		}
		```
2. **`useHttp`** - композабл по загрузке данных с сайта с использованием `useFetch` внутри, обработкой полученных данных и приведением их к единому интерфейсу ApiResponseList см. [[API-данные. Варианты запросов на получение данных|здесь]]). Есть непонятные ошибки:
	1. если вызывать в каком-либо компоненте в `<script setup>` асинхронно (с `await`) функцию из ts-файла, содержащую вызов данного композабла внутри, будет вылетать ошибка 500 о том, что вызов системной функции производится вне плагина, setup-функции или middleware;
	2. данная проблема решается, если обращение к композаблу `useHttp` писать напрямую в скрипте `<script setup>`, без вызова процедур-посредников, либо, *возможно, создать композабл на загрузку требуемых данных*;
	3. ==одно из изящных решений==, когда нужно производить загрузку API-данных, например, в хранилище и при этом не дублировать код (как было бы в п.2, если данные нужно подгружать на нескольких страницах) - создать **[[Промежуточное ПО (middleware) TODO!|специальное промежуточное ПО]]**, в котором просто описать все требуемые процедуры с непосредственным вызовом композабла. Данное ПО указывать явно в скрипте файла страницы;
3. **`usePageStore`** - композабл по извлечению данных по целой странице: контенту, баннеру и т.д. Подробности см. [[API-данные. Варианты запросов на получение данных|здесь]];
4. **`useHeroStore`** - аналогичный композабл по извлечению данных, но уже по части страницы, а именно баннеру. Подробности см. [[API-данные. Варианты запросов на получение данных|здесь]];
