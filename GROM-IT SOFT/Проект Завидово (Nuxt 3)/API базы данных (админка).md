2. ==Блоки с настройками страниц==, которые позволяют быстро через интерфейс обновлять данные в БД:
   
   ![[Pasted image 20231115103826.png|350]]
   
	1. по каждой странице есть свои блоки с данными, которые подлежат редактированию;
	2. следует иметь в виду, что блоки данных с текстовым содержимым (content) могут содержать html-теги, поэтому использование этих данных во vue-файлах должно производиться в блоках с использованием атрибута **`v-html`**: 
		```html
		<!-- текст под главным баннером в шапке страницы-->
		<div v-html="data?.content?.under_banner"></div>
		```
		![[Pasted image 20231120090611.png|500]]
	3. также *нужно обязательно либо проверять наличие `data`* перед включением этих данных в тег через атрибут `v-if`, либо использовать оператор опциональной цепочки "?" (как в примере выше);

3. ==Блоки с API-маршрутами==, к которым требуется обращаться асинхронными запросами с сайта:
   
   ![[Pasted image 20231115103913.png|150]] ^1a15a2
   
	1. **Список партнёров**:
		1. адрес `api/v1/partners`;
		2. фильтры:
			1. `has` - поиск ==только тех партнеров, которые связаны с сущностями==, например: нужны только те, для кого имеются активности, => `has = 'activities'` выведет список только нужных партнеров. Также можно искать по `restaurants`, `hotels`, `seasons` и т.д.;
			   
	3. **Список активностей** ("Чем заняться" на сайте):
		1. адрес `api/v1/activities`;
			   
	4. **Страница сайта** (для запросов извлечения данных по целой странице из базы):
		1. адрес `api/v1/page/{code}`;
	5. **Баннер для страницы** (для запросов извлечения данных по конкретному блоку баннера):
		1. адрес `api/v1/banner/{code}`;
