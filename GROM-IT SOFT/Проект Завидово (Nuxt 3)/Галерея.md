#vue-final-modal #галерея #Modal

Галерея открывается в специальном модальном модуле, расположенном в `src/galereya` (*см. проект "Завидово"*). Модуль состоит из элементов:
1. страница со списком альбомов/изображений `/pages/index.vue`;
2. список альбомов/изображений состоит из галерейных блоков **`./components/GalleryBlock.vue`**;
3. щелчок по блоку производит вызов функции *`openModal`*, расположенной в **плагине `src/plugins/vue-final-modal.ts`**, с параметрами:
	1. рабочий компонент фотографии, открывающейся в модальном окне галереи, см. далее;
	2. классы, которые можно дополнительно добавить для корневого элемента модального окна (см. классы в базовом модальном окне):

	```html
	<div
		class="gallery-block"
		@click="openModal(GalleryModal, { galleryIndex: index, class: 'modal-full' })"
	></div>
	```

4. рабочий компонент фотографии для модального окна галереи **`./components/GalleryModal.vue`**. Компонент выстраивается на базе модального компонента, содержимое этого компонента вставляется в слот в базовой модалке, см. далее;
5. базовое модальное окно **`src/components/Base/Modal.vue`**. Для модального окна есть особенность: в исходном классе максимальная ширина выставлена как `max-width: calc(100% - 40px);`. Чтобы такое предотвратить для галереи, следует в вызов `openModal` (см. п.3) добавить также класс `modal-full`, в котором прописана новая максимальная полная ширина блока:
