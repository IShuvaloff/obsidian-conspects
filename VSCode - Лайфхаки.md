
1. ==Горячие клавиши==:
	1. **Ctrl + P** - поиск файла проекта по названию;
	2. **Ctrl + Shift + P** - поиск системных команд по названию:
		* *Reload Window* - мягкая перезагрузка окна редактора без выхода из VSCode и, возможно, даже без закрытия проектов;
		* *Volar: Restart Vue Server* - мягкий рестарт всего сервера без закрытия окна VSCode;
		* *Preferences: Open Settings (UI/JSON)* - открыть окно системных настроек;
	3. **Ctrl + D** - найти и выделить следующий совпадающий с выделенной строкой строку. Аналогично зажатию Ctrl и простановке курсора в разные части кода перед одним и тем же словом/фразой. Т.е. порядок работы:
		* выделить текст для поиска;
		* нажать Ctrl + D - будет выделен такой же найденный фрагмент в файле;
		* продолжить нажатие Ctrl + D - пока не будут выделены все одинаковые фрагменты;
	4. Поиск и замена (выделить фрагмент текста и нажать):
		* **Ctrl + H** - производит поиск выделенного фрагмента *по текущему файлу* и предлагает заменить этот фрагмент вводимым значением (т.е. поиск + замена);
		* **Ctrl + Shift + H** - производит поиск выделенного фрагмента *по всему проекту* и предлагает заменить этот фрагмент вводимым значением (т.е. поиск + замена);
	5. **Ctrl + Shift + F** - отформатировать код в файле с учетом имеющихся настроек;
	6. **F2** - переименовать выбранное слово (функция, переменная и т.д.) во всех местах в файле, где оно встречается (а возможно, еще и в файлах с зависимостями, которые используют данную переменную);
	7. **F12** - перейти к месту объявления переменной (аналогично *Ctrl + MouseClick*);
	8. **Alt + MouseClick** - подобные клики в разных местах ставят несколько курсоров, позволяя редактировать код синхронно сразу в нескольких местах;
	9. **Alt + Shift + MouseClick** - выделяется текст от поставленного курсора до конца строки начиная от строки с курсором и заканчивая строкой, по которой установлен клик (например, нужно выделить несколько строк массива от определенной запиятой и до конца строки);
	10. Команды для расширения Lorem Ipsum:
		* **Ctrl + Shift + P -> Ctrl + Shift + P** - дважды Ctrl-Shift-P вставит на место курсора рандомный абзац;
		* **Ctrl + Shift + Ctrl-P -> P** - Ctrl-Shift-P и еще раз Ctrl-P вставляет выбранное количество абзацев; 
		* **Ctrl + Shift + L -> Ctrl + Shift + L** - дважды Ctrl-Shift-L вставить рандомную строку;
