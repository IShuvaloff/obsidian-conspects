# Слияние веток
## Подтягивание одной ветки в другую
Во время нахождения в нужной ветки `goalBranch` подтянуть все коммиты из другой ветки `srcBranch`:

```git
git merge srcBranch
```

## Ввод комментария к слиянию
### Через редактор Vim (по умолчанию)
Если в консоли появился фрагмент:

![[{675F510B-443E-426B-8A09-96EE8EDA08A2}.png|500]]

то курсор уже стоит в нужно месте (верхняя строка, где указан текст коммита по умолчанию - **Merge branch srcBranch into goalBranch**) и требуется дописать его (допустимо нажимать Enter либо вообще убирать шаблонную фразу и заменять ее на новую). Порядок действий:
1. поправить комментарий:
   
   ![[{EAD297A2-D751-4105-9643-E6BF0486EFBF}.png|500]]
   
2. для выхода из режима редактирования нажать **Esc**;
3. ввести команду:
	1. `:wq` - сохранение и выход из процесса коммита;
	2. `:q!` - выйти из режима мерджа без сохранения;
4. нажать **Enter**.

### Более простой способ средствами Windows/VSCode
В консоли ввести команду:
`git config --global core.editor "code --wait"`
- После этого при merge Git откроет обычный VSCode файл для сообщения коммита, а не Vim.
- Там просто ввести сообщение, сохраняешь и закрываешь файл — всё готово.
