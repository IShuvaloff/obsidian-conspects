#restore

1. Файлы были:
	* добавлены в индекс командой `git add`;
	* дополнительно изменены. 

	Отмена этих изменений до состояния *проиндексированного* файла проводится командой **`git restore`** - все последовавшие изменения будут безвозвратно удалены:

	```shell
	git restore filename.file
	```

2. Файлы были:
	* закоммичены через `git commit`;
	* дополнительно изменены, но *не добавлены в индекс*. 

	Отмена этих изменений до состояния *закоммиченного* файла проводится аналогичной командой **`git restore`** - все последовавшие изменения будут также безвозвратно удалены:

	```shell
	git restore filename.file
	```

3. Файлы были:
	* закоммичены через `git commit`;
	* дополнительно изменены, но *не добавлены в индекс*;
	* добавлены в индекс командой `git add`, но *не закоммичены*. 

	Как понятно из пунктов 1-2, вернуть эти изменения к состоянию закоммиченных файлов невозможно командой ==`git restore` - она отменяет только текущие изменения, не добавленные в индекс==. 
	
	Порядок отката изменений до состояния *закоммиченного* файла проводится в 2 этапа:
	1. отмена индексации файлов и возврат их просто к обычному измененному состоянию проводится командой **`git restore --staged`** - изменения в файле *не будут удалены*:
	
		```shell
		git restore --staged filename.file
		```

	2. отмена изменений до состояния закоммиченного файла см. в п.2 - вызывается командой **`git restore`** - теперь изменения в файле будут безвозвратно удалены:

		```shell
		git restore filename.file
		```
