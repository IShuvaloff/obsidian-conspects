#commit

Коммит - сохранение состояния текущей ветки.
1. создание нового сохранения - `git commit -m '...'` - с добавлением комментария;
2. внесение изменений в текущий коммит БЕЗ КОММЕНТАРИЯ - `git commit --amend --no-edit` - вносит текущие правки в последний коммит (важно: если он ранее был выгружен в удаленный репозиторий, возникнет проблема следующего push);
3. внесение изменений в текущий коммит С КОММЕНТАРИЕМ - `git commit --amend -m '...'`
