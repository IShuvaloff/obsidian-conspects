#git-push

### Удаление ветки в удаленном репозитории
`git push origin --delete remote-branch`

### Удаление ветки на локальном компьютере
`git branch -d local-branch`
* важно учесть, что при удалении локальной ветки нужно находиться в другой ветке.

### Очистка ссылок на удаленные ветки в репозитории
`git fetch --prune`

### Список веток в удаленном репозитории
`git branch -r`
