#app #config #global

По умолчанию внутри шаблонов (компонентов) из глобальных переменных, классов и функций доступны только некоторые:
```ts
const GLOBALS_ALLOWED =
  'Infinity, undefined, NaN, isFinite, isNaN, parseFloat, parseInt, decodeURI, decodeURIComponent, encodeURI, encodeURIComponent, Math, Number, Date, Array, Object, Boolean, String, RegExp, Map, Set, JSON, Intl, BigInt, console, Error, Symbol'
```

Задание глобальных переменных, доступных в любом месте, в любом шаблоне, делается через использование интерфейса `AppConfig`:

```ts
interface AppConfig {
	globalProperties: Record<string, any>
}

app.config.globalProperties.newVar = 'Значение новой переменной newVar';
```

Теперь в любом месте приложения будет доступна переменная **`newVar`** (не реактивная, как я понимаю).

Если в компоненте есть одноименная переменная, она будет иметь приоритет над глобальной.
