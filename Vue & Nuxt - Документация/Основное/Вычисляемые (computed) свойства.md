#computed

==Отличие от методов==:  метод вызывается каждый раз заново, если происходит обращение к нему в разных частях компонента, а computed-свойство кэшируется после первого вызова и вызовется повторно ТОЛЬКО при изменении хотя бы одной переменной, входящей в расчет. 

При создании вычисляемого свойства следует:
1. избегать изменения DOM;
2. не делать асинхронные запросы;
3. при необходимости изменения значения изменять источник, на основе которого вычисляемое свойство получено (но следует быть осторожным, т.к. при каждом изменении источника будет происходить новые перерасчет и следовательно вызов вычисляемого значения).

Ограничений можно избежать путем использования наблюдателей (`watch(...)`).

## Запись данных в computed
Можно использовать не только чтение вычисляемого свойства, но и [запись данных в него](https://ru.vuejs.org/guide/essentials/computed.html#writable-computed). Например:

```ts
const firstName = ref('John'); 
const lastName = ref('Doe'); 
const fullName = computed({ 
	get() { return firstName.value + ' ' + lastName.value }, 
	set(newValue) { 
		[firstName.value, lastName.value] = newValue.split(' ') 
	} 
});
```

> *В данном примере вычисляемое свойство складывается из имени и фамилии, но при попытке записать в переменную ФИО полную строку с данными, эта строка разбивается на 2 части и каждая записывается в свою переменную, из которых складывается ФИО. Технически вычисляемое свойство не перезаписывается, но позволяет отредактировать свои составные части и тем самым изменить свое значение.* 

## Возврат предыдущего значения
Можно получить предыдущее значение вычисляемого свойства через обращение к первому аргументу геттера `previous`:

```ts
const count = ref(2);
const alwaysSmall = computed((previous) => { 
	return count.value <= 3 ? count.value : previous;
})
```

> *В данном примере мы отображаем изменение значение переменной `count` в случае, если оно попадает в интервал, либо показываем последнее значение, которое входило в этот интервал. *
