##  **`v-html`** 
Позволяет вставить внутрь тега, где он применен, html-код (аналогично свойству `innerHTML`). Особенности:
1. считывает переменные ==без применения двоеточия== `:v-html` - некорректный вариант!
2. при использовании `scoped` стилей настроить стили получаемых компонентов внутри `v-html` можно только с помощью конструкции [`:deep(...)`](https://ru.vuejs.org/api/sfc-css-features.html#deep-selectors), внутрь скобок которого вставляется нужный тег или конструкция. Это используется потому, что в этом случае *на элементы навешиваются data-атрибуты, а в v-html не навешивается, потому что его содержимое рендерится после того как data-атрибуты будут добавлены, так же как и во вложенных компонентах*^[если стили не используются со `scoped`, то данная конструкция необязательна]:

	```css
	.company__text {
		:deep(span) {
			color: white;
		}
	}
	```

## **`v-scroll-lock`**
Динамически созданная директива, в данном случае через подключение пакета `body-scroll-lock` (см. npm):
1. добавляется плагин в папку `/plugins` через функцию [[Плагины (plugins)|defineNuxtPlugin]];
2. добавляется новая директива через функцию `nuxtApp.vueApp.directive(name, {mounted, updated, unmounted}` (см. [добавление директив Vue](https://v3.ru.vuejs.org/ru/guide/custom-directive.html#%D0%B2%D0%B2%D0%B5%D0%B4%D0%B5%D0%BD%D0%B8%D0%B5)) - в нашем случае `scroll-lock`
3. в каждом указанном хуке директивы выполняются действия из пакета, например:
	* при `mounted` блокируется тег `body` и все его содержимое через функцию `disableBodyScroll`;
	* при `unmounted` блокировка снимается через функцию `enableBodyScroll`;
	* и т.д.;
4. теперь в нужном теге можно использовать директиву через атрибут, включающий специальный префикс `v-scroll-lock`. При навешивании директивы на компонент все остальные элементы в body будут блокироваться для прокрутки (*см. пример в проекте "Завидово"*);
5. используется в первую очередь для модальных окон:

## **`v-model`**
Передача переменной внутрь компонента с возможностью возврата в случае, если оно было изменено внутри этого компонента. Предполагает порядок действий:
1. передача внутрь компонента переменной `v-model="variable"`;
2. внутри компонента во входящих параметрах (`props`) нужно указать `modelValue`;
3. в компоненте следует зарегистрировать событие `update:modelValue` по изменению входящего параметра:
   
```ts
const emit = defineEmits(['update:modelValue']);
```
	   
1. в нужный момент, чтобы вернуть назад измененное значение, нужно инициировать процедуру события `emit("update:modelValue", value)`, где value - это передаваемое назад измененное значение. В родителе можно отследить данное событие с помощью директивы `@@update:model-value`;
2. при этом **нельзя напрямую редактировать параметр** `modelValue`, т.к. входящие компоненты являются только READONLY!
3. *в родителе можно отследить также любое событие*, чтобы выполнить те или иные действия внутри него. Например, если срабатывает `emit` с возвратом назад значение, то можно передать это значение в качестве параметра в обработчик события в родителе^[главное, чтобы название процедуры не являлось зарезервированным значением!]:

## **`v-bind`**
Привязывание переменной к какому-либо атрибуту в теге для передачи ему динамического значения. Варианты использования:
1. с использованием `v-bind`:
   
   ```html
   <div v-bind:id="dynamicId"></div>
	```   
   
2. через сокращенную запись `:`:
   
   ```html
   <div :id="dynamicId"></div>
	```
   
3. через одноименное сокращение (в случае, если переменная называется не `dynamicId`, а `id`):
   
   ```html
   <div :id></div> 
   <div v-bind:id></div>
	```
   
4. булевы атрибуты (данный атрибут присваивается html-элементу только в случае, если значение - либо пустая строка `''`, либо `false`):
   
   ```html
   <button :disabled="isButtonDisabled">Кнопка</button>
	```
   
5. динамическая привязка сразу нескольких атрибутов через `v-bind` без уточнения имени:
   
   ```ts
   const objectOfAttrs = { 
	   id: 'container', 
	   class: 'wrapper', 
	   style: 'background-color:green',
	}
	```
	```html
	<div v-bind="objectOfAttrs"></div>
	```

6. подвязка динамического атрибута - можно определить значение атрибута в переменную `attributeName`^[можно использовать только готовое имя для подстановки в html; выражения внутри квадратных скобок в html не допускаются!] и использовать ее в html-коде (актуально для тегов `<nuxt-link :to="">` и `<a :href="">`)^[Ожидается использование string в качестве значения переменной. Если значение переменной null, то это заменяет собой явное отключение/удаление/отсутствие атрибута]:
   
   ```html
	   <a v-bind:[attributeName]="url"> ... </a>
	   <a :[attributeName]="url"> ... </a>
	```

Особенности проброса внутрь **id**, **class** и **style**:
1. от родителя к внутреннему тегу ==автоматически прокидываются== как минимум 3 атрибута: **class**, **style** и **id**, но только в случае одного элемента в шаблоне компонента;
2. если надо предотвратить наследование, то внутри компонента надо задать `defineOptions({ inheritAttrs: false, })`;
3. если элементов в шаблоне несколько, то можно задать явный из них, куда эти свойства прокинутся, через атрибут внутреннего элемента `<div v-bind="$attrs">` (ну или через использование композабла **useAttrs()** в Composition API).

## **`:key`** 
[Атрибут](https://vueframework.com/docs/v3/ru/ru/api/special-attributes.html#key), изменение которого приводит к ререндерингу (перерисовке) компонента. ==Полезно в случаях==:
1. *для случаев изменения ширины экрана* (например, при его развороте, если внутренний контент подразумевает изменение^[например, изменение URL изображений вследствие смены его размеров через ImageProxy];
2. *при необходимости перерисовать страницу* (например, если в глобальном middleware делаем переход на другую страницу через `navigateTo(...)` - в этом случае новая страница может отрисоваться поверх старой, см. проект "Оффпрайс Nuxt 3");

## **`v-if`**/**`v-else-if`**/**`v-else`**
Директивы условия, при которых в случае false компонент не будет включен в DOM;

## **`v-show`**
Директива условия, при которой, в отличие от предыдущих, при значении false компонент будет включен в DOM, но с css-свойством `display: none`;

## **`v-on`**
Директива отслеживания событий DOM, можно заменить на @. Аналогично использованию динамических атрибутов в `v-bind` здесь можно также использовать динамическое событие, задаваемое текстом в переменную `eventName`:

```html
<a v-on:[eventName]="doSomething"> ... </a>
<a @[eventName]="doSomething"> ... </a>
```
