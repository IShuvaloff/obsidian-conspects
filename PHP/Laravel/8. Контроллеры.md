#controllers

## Назначение
Перенести логику из файла с маршрутами в отдельные классы. Например, маршрут, связанный с пользователями, может отправлять все запросы к одноименному контроллеру, в котором будут собраны все требуемые операции с пользователем, включая CRUD, а также переход на нужную страницу. 

## Создание 
1. место размещения контроллеров - `/app/Http/Controllers/`;
2. создание нового контроллера - команда `php artisan make:controller UserController`;
3. может иметь множество публичных методов, каждый для своего запроса:
	```php
	namespace App\Http\Controllers;
	use App\Models\User;
	use Illuminate\View\View;
	
	class UserController extends Controller {
		public function show(string $id): View {
			return view('user.profile', [
				'user' => User::findOrFail($id)
			]);
		}
	}
	```
1. обращение к контроллеру из маршрута:
	```php
	use App\Http\Controllers\UserController;
	
	Route::get('/user/{id}', [UserController::class, 'show']);
	```
	В этом случае динамические параметры маршрута отправляются в метод `show(id)` контроллера.

#### Контроллеры одного действия
1. создаются, когда контроллер содержит всего лишь один метод. В этом случае его название можно заменить на `__invoke()`, а вызывать контроллер можно через простое обращение к классу:
	```php
	// контроллер
	class ShowProfile extends Controller {
	    public function __invoke($id) {
	        $user = User::findOrFail($id); 
	        return view('user.profile', ['user' => $user]);
	    }
	}
	
	// маршрут
	use App\Http\Controllers\ShowProfile;
	Route::post('/user/{id}', ShowProfile::class);
	```
1. команда на создание - `php artisan make:controller ProvisionServer --invokable`

## Подключение миддлваров
Способы подключения миддлваров к исполняемому коду:
1. через [[7. Миддлвары#Подключение к маршрутам|подключение к маршруту]]:
	```php
	Route::get('/profile', [UserController::class, 'show'])->middleware('auth');
	```
2. через расширение контроллера интерфейсом `HasMiddleware`:
	```php
	use Illuminate\Routing\Controllers\HasMiddleware;
	use Illuminate\Routing\Controllers\Middleware;
	
	class UserController implements HasMiddleware {
		public static function middleware(): array {
	        return [
	            'auth',
	            new Middleware('log', only: ['index']),
	            new Middleware('subscribed', except: ['store']),
	        ];
	    }
	}
	```
	- подключается глобально зарегистрированный миддлвар `auth`;
	- подключаются миддлвары `log` и `subscribe`;
1. создание инлайновых миддлваров:
	```php
	class UserController implements HasMiddleware {
		public static function middleware(): array {
		    return [
		        function (Request $request, Closure $next) {
		            return $next($request);
		        },
		    ];
		}
	}
	```

## Контроллеры ресурсов
Ресурсом можно назвать класс каждой модели. Для ресурсов характерны операции CRUD, поэтому создать их можно через команду `php artisan make:controller ResController --resource`. Будет создан шаблон с указанными методами.
