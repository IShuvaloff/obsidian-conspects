[Хелперы](https://laravel.com/docs/12.x/helpers) - обертки Laravel над функциями php. Работают аналогичным образом, что и [фасады (Facades)](https://laravel.com/docs/12.x/facades#facade-class-reference) - как вызов какого-либо функционала через *статичный классовый метод* для укорачивания длины кода.

## Обертки над PHP

|Описание действия|Laravel-хелпер|Аналог на чистом PHP|
|---|---|---|
|Вывести переменную в читаемом виде, продолжить выполнение|`dump($var)`|`var_dump($var);`|
|Вывести переменную и остановить выполнение|`dd($var)`|`var_dump($var); exit;`|
|Вывести переменные с меткой и остановить выполнение|`ddd($var)` (Laravel 9+)|`echo '<pre>'; var_dump($var); echo '</pre>'; exit;`|
|Логировать информацию в файл логов Laravel|`Log::info($var)`|`error_log(print_r($var, true));`|
|Вызвать исключение с редиректом на страницу ошибки|`abort(403)`|`http_response_code(403); die('Access denied');`|
|Вызвать исключение с сообщением (для отладки)|`abort(403, 'Access denied')`|`http_response_code(403); die('Access denied');`|
|Проверка существования ключа в массиве/объекте с удобным хелпером|`data_get($array, 'user.name')`|`$value = isset($array['user']['name']) ? $array['user']['name'] : null;`|
|Преобразовать значение в булевый тип|`boolval($value)`|`boolval($value)` (PHP встроенный)|
|Получить текущий URL|`url()->current()`|`$_SERVER['REQUEST_URI']`|

## Глобальные функции-хелперы:

|Действие|Глобальный доступ|Аналог|
|---|---|---|
|Получить доступ к глобальному объекту приложения Application|`app()`|`$this->app` (внутри сервис-провайдера)|
|Обратиться к движку Inertia для рендеринга страницы|`inertia(...)`|`Inertia::render(...)`|
|Получить маршрут по имени (если имя зарегистрировано в web.php)|`route('route_name')`||
|Выполнить редирект по маршруту|`redirect()->route('route_name')`||
|Выполнить переход по маршруту, с параметрами (все параметры, не входящие в список динамических, будут обращены в query-params|`to_route('route_name', ['param1' => 1])`||
