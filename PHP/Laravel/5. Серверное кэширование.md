#cache
## Привязка тегов к кэшу
К кэшированным данным можно привязывать теги (метки), чтобы управлять через эту метку сразу несколькими кэшами, например, для их очистки.
Особенности:
1. можно привязывать любое количество меток;
2. **сохранение с тегами** - используется метод `Cache::tag` вокруг метода `Cache::remember` для помечания тегами (в примере кэш `item_NNN` помечается тегами `items` и `category_FFF`):
	```php
	Cache::tags(['items', 'category_' . $categoryId])->remember(
		"item_{$slug}", 
		3600, 
		function () use ($slug) {
			return Item::where('slug', $slug)->firstOrFail();
		}
	);
	```
3. **получение записи с тегами** - получить кэш, помеченный определенным тегом или тегами:
	```php
	Cache::tags(['items'])->get("item_{$slug}");
	```
4. **массовая очистка** кэшей по тегу - примеры:
	1. для массового обновления данных:
		```php
		// Удалит все записи, связанные с тегом 'items' и вернет результат 
		public function flushItems(): RedirectResponse { 
			Cache::tags(['items'])->flush(); 
			return back()->with('success', 'Все кешированные товары очищены'); 
		}
		```
	2. при удалении категории:
		```php
		public function destroy($categoryId) {
		    // удалять саму категорию + кэш всех items этой категории
		    Category::findOrFail($categoryId)->delete();
		    Cache::tags(["category_{$categoryId}"])->flush();
		}
		```
