#провайдер #фасад #контейнер 

Этапы создания приложения Laravel:

## Стартовая точка
`/public/index.php` - сервер *Nginx* / *Apache* обращаются к этому файлу:
1. открытие автозагрузчика *Composer*
2. запрос на создание объекта приложения Laravel (обращение к файлу далее);

## Создание объекта приложения Laravel
Происходит в файле `/bootstrap/app.php` - задан порядок выполнения команд.

#### Конфигурирование приложения
Вызов функции `Application::configure()` в том числе для подключения [[3. Сервисы и фасады|сервисов]] в проект ==для глобального использования==.
#### Регистрация маршрутов
- маршруты на страницы лежат в файле `/routes/web.php`;
- регистрация маршрутов производится путем вызова функции `->withRouting(...)`;
- если создан доп. файл с маршрутами, его можно подключить через функцию `then`:
	```php
	use Illuminate\Support\Facades\Route;
	
	->withRouting(
	    web: __DIR__.'/../routes/web.php',
	    commands: __DIR__.'/../routes/console.php',
	    health: '/up',
	    then: function () {
	        Route::middleware('api')
	            ->prefix('webhooks')
	            ->name('webhooks.')
	            ->group(base_path('routes/webhooks.php'));
	    },
	)
	```
#### Регистрация миддлваров
- регистрация миддлваров производится путем вызова функции `->withMiddleware(...)`.
#### Регистрация исключений
- регистрация исключений производится путем вызова функции `->withExceptions(...)`.

## Обращение к ядру
* Ядро **HTTP Kernel** =>  `handleRequest`;
* Ядро **console kernel** => `handleCommand`;
Они находятся в одной из системных папок Laravel (*Illuminate/Foundation/Http/Kernel*).

## Создание массива *bootstrappers*
Они предварительно запускают обработку конфигурационных файлов из папки `/config`, которые тянут значения из **главного файла настроек** `.env`, а при их отсутствии подставляют дефолтные значения. Кстати информацию о настройках движка можно также посмотреть в консоли командой `php artisan about`.

## Отработка миддлваров 
Прогон запроса через массив миддлваров, привязанных к проекту, которые отвечают за:
* чтение и запись [**HTTP-сессии**](https://laravel.com/docs/12.x/session) в глобальное хранилище для доступа из любого места на сайте (по умолчанию - в текущую БД);
* [**CSRF-защиту**](https://laravel.com/docs/12.x/csrf) (от хакерских атак) - создание уникального токена для всех API-запросов каждый раз при пересоздании сессии и хранение его в созданной сессии;

## Выполнение запроса
Выполнение переданного запроса (request) и возврат ответа (response).
