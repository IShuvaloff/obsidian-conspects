#flash

Это данные, возвращаемые **из контроллера** Laravel после выполнения запроса на фронт. Данные привязываются к ключу. Пример возврата в файле `AnyController.php`:
```php
return back()->with('anyKey', 'Любое сообщение');
```

Доступ к флэш-сообщению на фронте осуществляется через пропсы, а обновляется сообщение в хуке `onSuccess()`^[факт успешного выполнения запроса. Возможные хуки: `onSuccess`, `onError`, `onFinish`, `onCancel` и др., см. документацию [Inertia](https://inertiajs.ru/manual-visits#%D0%BE%D0%B1%D1%80%D0%B0%D1%82%D0%BD%D1%8B%D0%B5-%D0%B2%D1%8B%D0%B7%D0%BE%D0%B2%D1%8B-%D1%81%D0%BE%D0%B1%D1%8B%D1%82%D0%B8%D0%B9)] выполненного API-запроса:
```ts
import { usePage, router } from '@inertiajs/vue3'

router.delete(
	route('categories.destroy', 
	{ id }), 
	{
		onSuccess: () => {
			const msg = usePage().props.flash?.anyKey;
		    if (msg) alert(msg);
		}
	}
)
```
