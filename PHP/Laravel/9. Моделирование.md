## Общее устройство и модели

> **Идея**: каждая таблица БД представлена **моделью**, через неё делается весь CRUD.

### Базовые команды

| Что | Команда / код | Пояснение |
|-----|---------------|-----------|
| Создать модель | `php artisan make:model Flight` | Базовая модель `Flight` в `app/Models`. |
| Создать модель «со всем» | `php artisan make:model Flight --all` | Сразу: миграция, factory, seeder, policy, controller, form request. |
| Миграция + модель | `php artisan make:model Flight -m` | Модель + миграция. |
| Factory | `php artisan make:model Flight -f` | Модель + фабрика. |
| Seeder | `php artisan make:model Flight -s` | Модель + сидер. |
| Controller | `php artisan make:model Flight -c` | Модель + контроллер. |
| Pivot-модель | `php artisan make:model Flight -p` | Модель для pivot-таблицы. |
| Показать инфо о модели | `php artisan model:show Flight` | Структура полей, связи, касты и т.д. |

### Основные конвенции

| Тема | Пример / параметр | Суть |
|------|-------------------|------|
| Имя таблицы | `Flight` → `flights` | snake_case + множественное число. |
| Своя таблица | `protected $table = 'my_flights';` | Переопределить имя таблицы. |
| Подключение | `protected $connection = 'mysql2';` | Своя БД для конкретной модели. |

## Ключи, UUID/ULID, timestamps

### Первичный ключ

| Тема | Код | Суть |
|------|-----|------|
| Имя поля | `protected $primaryKey = 'flight_id';` | Если PK не `id`. |
| Автоинкремент | `public $incrementing = false;` | Отключить автоинкремент. |
| Тип ключа | `protected $keyType = 'string';` | Например, для UUID. |
| Композитный PK | — | **Не поддерживается**. |

### UUID / ULID

| Что | Код | Суть |
|-----|-----|------|
| UUID | `use HasUuids;` | Генерация UUID, хранить в строковом PK. |
| ULID | `use HasUlids;` | Аналогично, но ULID. |
| Кастомная генерация | `protected function newUniqueId(): string { ... }` | Свой генератор. |
| Несколько UUID-полей | `public function uniqueIds(): array { return ['id', 'other_uuid']; }` | Указать поля для auto-UUID. |

### Timestamps и формат дат

| Что | Код | Суть |
|-----|-----|------|
| Отключить timestamps | `public $timestamps = false;` | Не писать `created_at` / `updated_at`. |
| Имена полей | `const CREATED_AT = 'created';`<br>`const UPDATED_AT = 'updated';` | Свои колонки. |
| Формат хранения | `protected $dateFormat = 'U';` | Например, UNIX timestamp. |
| Временное отключение | `Model::withoutTimestamps(fn () => ...)` | Выполнить блок без обновления timestamps. |

## Строгий режим и атрибуты

### Атрибуты и значения по умолчанию

| Что | Код | Суть |
|-----|-----|------|
| Дефолты | `protected $attributes = ['options' => '[]', 'delayed' => false];` | Значения по умолчанию при создании. |

### Строгий режим модели

| Что | Код / настройка | Зачем |
|-----|------------------|-------|
| Запрет ленивых связей | `Model::preventLazyLoading();` | Ловить места без eager loading. Обычно включать в dev. |
| Запрет тихого игнора атрибутов | `Model::preventSilentlyDiscardingAttributes();` | Если в mass assignment прилетело лишнее поле — кидать исключение, а не молча игнорить. |

## Выборка и коллекции

### Базовые операции выборки

| Что | Код | Суть |
|-----|-----|------|
| Все записи | `Flight::all();` | Получить **всю** таблицу. |
| Условия | `Flight::where('active', 1)->get();` | Фильтрация как в Query Builder. |
| Сортировка | `Flight::orderBy('created_at', 'desc')->get();` | Сортировка. |

### Получение одной модели

| Что | Код | Суть |
|-----|-----|------|
| По PK | `Flight::find(1);` | `null`, если нет. |
| Первый по условию | `Flight::where(...)->first();` | `null`, если нет. |
| Сокращение | `Flight::firstWhere('active', 1);` | Эквивалент `where(...)->first()`. |
| С fallback | `Flight::findOr(fn () => ...);` | Если нет — выполнить замыкание. |
| Первый с fallback | `Flight::firstOr(fn () => ...);` | Аналогично, но по условию. |
| Обязательно найти | `Flight::findOrFail(1);` | Исключение `ModelNotFoundException`, удобно в контроллерах. |
| Обязательно найти по условию | `Flight::where(...)->firstOrFail();` | То же, но с `where`. |

### Обновление/перезагрузка моделей

| Что | Код | Суть |
|-----|-----|------|
| Свежая копия | `$flight->fresh();` | Возвращает **новый** инстанс из БД. |
| Обновить текущую | `$flight->refresh();` | Обновляет объект и его связи inplace. |

### Коллекции

- Возвращается **`Illuminate\Database\Eloquent\Collection`**, которая:
  - наследует `Collection`;
  - работает с теми же методами (`map`, `filter`, `reject`, `each`, …);
  - «знает», что внутри — модели.

## Обработка больших выборок

### Chunk / Lazy / Cursor

| Подход | Код | Задача |
|--------|-----|--------|
| `chunk` | `Flight::chunk(200, function ($flights) { ... });` | Обработка большими порциями, несколько запросов. |
| `chunkById` | `Flight::chunkById(200, fn ($flights) => ...);` | То же, но по ID, безопасно при обновлениях. |
| `lazy` | `Flight::lazy(200)->each(fn ($flight) => ...);` | Возврат `LazyCollection`, ленивый стрим поверх chunk. |
| `lazyById` | `Flight::lazyById(200)->each(...);` | Лениво по ID. |
| `cursor` | `Flight::cursor()->each(fn ($flight) => ...);` | Один запрос, курсор, в памяти по одной модели, но **без** eager loading. |

## Подзапросы и агрегаты

### Подзапросы в select / orderBy

Пример (общее по смыслу):

```php
Flight::addSelect([
    'last_flight_at' => FlightLog::select('created_at')
        ->whereColumn('flight_logs.flight_id', 'flights.id')
        ->orderByDesc('created_at')
        ->limit(1),
])->get();
```

- **Идея**: добавить вычисляемое поле через подзапрос.
    
- Аналогично используется в `orderBy(Subquery)` для сортировки по вычисленному значению.
    

### Агрегаты

|Что|Код|Суть|
|---|---|---|
|Кол-во|`Flight::count();`|Количество записей.|
|Максимум|`Flight::max('price');`|Максимум по столбцу.|
|Сумма|`Flight::sum('seats');`|Сумма.|
|Среднее|`Flight::avg('price');`|Среднее значение.|

## Создание и обновление записей

### Создание

|Подход|Код|Комментарий|
|---|---|---|
|Через `new + save`|`php\n$flight = new Flight;\n$flight->name = 'Test';\n$flight->save();\n`|Простая, явная вставка.|
|Через `create`|`Flight::create(['name' => 'Test']);`|Требует настроенных `$fillable` / `$guarded`.|

### Обновление

|Подход|Код|Комментарий|
|---|---|---|
|Найти и сохранить|`php\n$flight = Flight::find(1);\n$flight->name = 'New';\n$flight->save();\n`|Обычное обновление.|
|Массовое обновление|`Flight::where('active', 0)->update(['active' => 1]);`|Одним запросом, **без** `saving/updated` событий.|

### firstOrCreate / firstOrNew / updateOrCreate

|Метод|Код|Поведение|
|---|---|---|
|`firstOrCreate`|`Flight::firstOrCreate(['code' => 'X'], ['name' => 'Test']);`|Ищет по **условиям**, если нет — создаёт и **сохраняет**.|
|`firstOrNew`|`Flight::firstOrNew(['code' => 'X'], ['name' => 'Test']);`|Ищет или создаёт **без** `save()` — нужно вызвать вручную.|
|`updateOrCreate`|`Flight::updateOrCreate(['code' => 'X'], ['name' => 'Test']);`|Если запись есть — обновляет, если нет — создаёт.|

## Отслеживание изменений

### Проверки состояния атрибутов

|Что|Код|Суть|
|---|---|---|
|Есть ли изменения|`$flight->isDirty();`|Изменялись ли какие-то атрибуты.|
|Изменилось ли поле|`$flight->isDirty('name');`|Конкретное поле.|
|Чистая модель|`$flight->isClean();`|Ничего не менялось.|
|Что изменилось при последнем `save`|`$flight->wasChanged();` / `$flight->wasChanged('name');`|Флаг / конкретное поле.|

### Доступ к прошлым значениям

|Что|Код|Суть|
|---|---|---|
|Оригинальные значения|`$flight->getOriginal();`|Весь набор атрибутов до изменений.|
|Оригинал поля|`$flight->getOriginal('name');`|Конкретное поле.|
|Какие поля изменились|`$flight->getChanges();`|Массив «поле → новое значение» после `save()`.|
|Предыдущие значения|`$flight->getPrevious();`|Значения до последнего сохранения.|

## Mass Assignment и upsert

### Mass Assignment

|Тема|Код|Суть|
|---|---|---|
|Разрешённые поля|`protected $fillable = ['name', 'code'];`|Белый список для `create()` / `fill()`.|
|Запрещённые поля|`protected $guarded = ['is_admin'];`|Чёрный список.|
|Разрешить всё|`protected $guarded = [];`|Всё можно mass-assign, **опасно** для открытых входов.|
|JSON-ключи|`protected $fillable = ['options->enabled'];`|Mass assignment для JSON-полей.|

### upsert

|Что|Код|Суть|
|---|---|---|
|upsert|`php\nFlight::upsert([\n ['code' => 'X', 'name' => 'A'],\n ['code' => 'Y', 'name' => 'B'],\n], ['code'], ['name']);\n`|Для каждой записи по `code`: если есть — обновить `name`, если нет — вставить. Требует **уникальных/PK** индексов.|

## Удаление и Soft Deletes

### Удаление

|Подход|Код|Комментарий|
|---|---|---|
|Удалить модель|`$flight->delete();`|Учитывает soft deletes (если включены).|
|Удалить по PK|`Flight::destroy(1);` / `Flight::destroy([1, 2]);`|Без предварительного `find()`.|
|Массовое удаление|`Flight::where('active', 0)->delete();`|Удаление по условию, без событий `deleting/deleted`.|

### Soft Deletes

|Что|Код|Суть|
|---|---|---|
|Включить SoftDeletes|`php\nuse SoftDeletes;\n\n$table->softDeletes();\n`|Добавляет `deleted_at`, скрывает записи из обычных запросов.|
|Проверить, удалена ли запись|`$flight->trashed();`|`true`, если запись помечена как удалённая.|
|Жёсткое удаление|`$flight->forceDelete();`|Физическое удаление записи из БД.|
