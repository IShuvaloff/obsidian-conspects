#xampp #open-server #laragon

1. XAMPP. *Проблема* с разворачиванием готового проекта:
	1. перенастройка конфигурационных файлов, простановка абсолютных путей;
	2. большое количество ошибок 500 при подгрузке проекта;
	3. ошибки в загрузке стилей при попытке использовать протокол HTTPS;
	4. в целом устаревшая и негибкая версия сервера;
2. Laragon: 
	1. удобно разворачивать новый проект;
	2. есть возможность задать имя хосту вместо *localhost* (ЧПУ);
	3. *сложности* с путями, т.к. фактический путь не совпадает с путем в браузере;
3. [**OpenServer 6.0**](https://ospanel.io/):
	1. Документация:
		1. [официальная]((https://github.com/OSPanel/OpenServerPanel/wiki/%D0%94%D0%BE%D0%BA%D1%83%D0%BC%D0%B5%D0%BD%D1%82%D0%B0%D1%86%D0%B8%D1%8F)) (читать внимательно!);
		2. неофициальная, от сотрудника OSPanel:
			* [быстрый старт](https://delphinpro.ru/a/7);
			* [подключение phpMyAdmin](https://delphinpro.ru/a/6) (в комплект установки OSPanel 6 не входит, но после установки создает отдельный сервер с базами данных);
	1. позволяет отдельно настроить для каждого проекта в файле `<project>/.osp/config.ini` нужные версии ПО - php, mysql и т.д. (*см. п. 3.3 ниже*);
	2. позволяет подключить к фоновой программе несколько требуемых версий php и БД, работающих параллельно, через консоль или иконку в трее:
