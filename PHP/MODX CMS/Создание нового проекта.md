## Разворачивание проекта
Разворачивание проекта доступно на различных серверах, XAMPP, Laragon, Apache и т.д. Подробная инструкция по установке проекта MODX:

Ключевые особенности **разворачивания проекта на XAMPP**:
1. выполнить все действия из видео выше;
2. разблокировать файлы .htaccess в корне проекта `/modx-project/ht.access` и в папке `/modx-project/core/ht.access` путем переименования их в **.htaccess**; 
3. в файле ==D:\xampp\htdocs\modx-project\\.htaccess== (настройки сервера) изменить параметр `RewriteBase /`  на адрес проекта *modx-project*, т.к. базой считается хост, который имеет адрес *127.0.0.1*^[адрес любого создаваемого на локальном компьютере сервера или другими словами *localhost*], тогда как вход в проект выполняется путем приписывания названия проекту к хосту. Таким образом, требуется выставить следующее значение: `RewriteBase /modx-project/`^[это требуется для того, чтобы в проекте начали работать дружественные URL, т.е. переходы по внутренним ресурсам с помощью визуально понятных ссылок. Например, адрес страницы без данной настройки будет выглядеть как `/modx-project/?id=...`, где id - уникальный ключ страницы в админке MODX. При включении дружественных URL адрес преобразится в `/modx-project/page`].
