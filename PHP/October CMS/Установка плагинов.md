#october_cms_plugins

Выбор и установка плагинов производится в интерфейсе в блоке *Настройки/Обновления системы/Установить пакеты*:

![[Pasted image 20231027185642.png]]

Часто плагин используется на какой-либо странице, например, плагин блога. Порядок действий здесь таков:
1. создать в редакторе новую страницу;
2. в код страницы перетянуть из блока "Компоненты" (над кодом) нужный компонент (например, из Блог - список записей^[обычно каждый плагин заключает в себе множество различных функций, блоков и др. элементов]):
   
   ![[Pasted image 20231027190035.png]]

3. как видно из скриншота, видно, что открылся список всех доступных внутри программы компонентов. Нужно выбрать "Блог" и из него "Список записей блога", перетащить в область кода, будет вставлена строка с требуемым компонентом, а над кодом появится в серой окантовке строка с названием подключенного компонента;
4. после этого при переходе на созданную страницу мы увидим список постов блога.
