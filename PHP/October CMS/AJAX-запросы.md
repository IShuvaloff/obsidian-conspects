#october_cms_ajax

**October AJAX**-запросы позволяют перерендерить нужные блоки кода в зависимости от изменений, происходящих на клиенте (в браузере). Подробности можно узнать [здесь](https://docs.octobercms.com/3.x/cms/ajax/introduction.html)

==Порядок обновления данных по запросу==:
1. создание на клиенте запроса серверу с указанием названия обработчика^[функция на сервере для обновления данных и перерендеринга блока кода] и др. (необязательных) параметров;
2. выполнение запроса на сервере внутри указанного обработчика;
3. перерендеринг (визуализация) html-фрагмента (partial) на сервере с учетом обновленных данных;
4. возврат обновленного html-фрагмента назад клиенту и перерисовка части этого кода на странице.
