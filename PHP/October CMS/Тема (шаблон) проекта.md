#october_cms_theme #october_cms_template

**Темы** (или **шаблоны**) - полное [содержимое](https://docs.octobercms.com/3.x/setup/directory-structure.html) сайта,  располагаются в проекте October CMS, внутри корневой папки `/themes`. Принцип архитектуры - модульная, т.е. в указанную папку добавляется новая папка с мини-модулем темы, внутри которой есть следующие директории:
* `/assets` - изображения, стили, доп. скрипты и папка `/assets/vendor`, где располагаются доп. плагины/библиотеки, устанавливаемые непосредственно для темы;
* `/layouts` - ==**[[Макет темы (layout)|макеты]]**== веб-страниц, которых может быть несколько в зависимости от того, для какой из страниц этот макет будет применяться. Файлы макета включают в себя все, что повторяется на каждой странице, например теги HTML, HEAD и BODY, ссылки на CSS и JavaScript, также меню навигации и футер страницы^[например, на домашней странице может не быть верхнего колонтитула или меню навигации может отличаться от всех остальных таблиц, поэтому будет минимум 2 макета: home.htm и main.htm];
* `/content` - **контент** - здесь могут располагаться отдельные файлы html-кода, которые содержатся в файлах формата **`.htm`**. Кроме того, здесь располагается папка `/content/ajax`, где лежат обычные текстовые файлы, например, с js-содержимым;
* `/partials` - отдельные **фрагменты** html-кода в файлах формата **`.htm`**, используемые в коде страниц. Служат для упрощения кода больших и сложных страниц;
* `/pages` - конкретные ==**[[Страница темы (pages)|страницы темы]]**== также в формате **`.htm`**, собранные от начала и до конца, в т.ч. с использованием блоков кода из `/partials`, стилей из `/assets`. Страницы отображаются внутри макетов с помощью тега страницы, который следует вызывать в коде макета. Теоретически, *обязателен только этот раздел*, т.к. все остальное - это лишь составные части страниц, которые можно и не выносить в отдельные модули;
* `/vendor` - файлы установленных пакетов Composer (системы в целом). Имеют приоритет над аналогичными файлами отдельных компонентов.
