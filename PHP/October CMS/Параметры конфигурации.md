#october_cms_configs

Параметры конфигурации проекта настраиваются в файлах в директории `/config` в корне проекта.

1. `cms.php`:
	1. Активная тема при загрузке сайта: `active_theme`;
	2. Безопасный режим, включающий шаблонизатор Twig для предотвращения запуска стороннего php-кода: `safe_mode`^[`null` по умолчанию - работает только в режиме отладки];
2. `system.php`:
	1. Список деактивированных плагинов: `disable_plugins`;
	2. Механизм предотвращения случайных запросов (включен по умолчанию): `enable_csrf_protection`;
	3. Конкретный список загружаемых модулей: `load_modules` (по умолчанию загружаются все доступные в системе);
3. `app.php`:
	1. Режим отладки^[не должен быть включен в рабочей версии проекта]: `debug`;
4. `database.php`:
	1. В конфигурации [базы данных](https://docs.octobercms.com/3.x/setup/database-config.html) для `connections.mysql` установить свойство `'varcharmax': 191,`:

В целом конфигурация, включающая безопасность, производительность и другие параметры веб-сервера настраивается [здесь](https://docs.octobercms.com/3.x/setup/web-server-config.html).

**ВАЖНАЯ ЗАМЕТКА**:
Если пользуемся тестовой и боевой админками, то ==часовой пояс пользователя и там, и там должен совпадать==! Иначе форматирование одних и тех же записей с одинаковым временем, которое заносилось в базу, будет выводить в итоге совершенно разный результат. Данные сохраняются в БД в UTC-формате, а затем в [[Vue.js/ПОЛЕЗНЫЕ ДАННЫЕ|dayjs]] трансформируются в нужный формат.
