#config #october_cms

1. Создать базу данных в `phpMyAdmin` (зайти на страницу через кнопку Admin сервера Apache в приложении XAMPP) + нового пользователя со всеми правами и ролями (ALL_PRIVILEGIES)^[возможно, в последних версиях October CMS можно создать и базу, и пользователя во время инсталляции сайта, нужно проверить];
2. ==Установка через интерфейс на сайте==:
	1. Создать новую директорию проекта `NewProject` в папке локального сервера (на Apache-сервере это `XAMPP/htdocs`);
	2. Перейти на страницу сервера localhost^[либо localhost:PORT, если выбран порт не по умолчанию] и затем на страницу директории проекта `http://localhost/NewProject`;
	3. В открывшемся списке файлов найти install.php и добавить в адресную строку название файла: `http://localhost/NewProject/install.php`, запустить;
	4. Пройти визард с настройками^[здесь как раз могут быть настройки базы и пользователя], обязательно сменить адрес страницы администратора^[сейчас это /admin, прежде было /backend, но это легко угадываемые адреса, требуется создать более уникальный], запустить установщик. **САЙТ ЗАПУЩЕН** на локальном сервере;
3. ==Установка через терминал==:
	1. Открыть в терминале папку `XAMPP/htdocs`;
	2. Запустить команду `composer create-project october/october new-project`;
	3. После создания директории со стартовыми файлами перейти в папку с созданным проектом^[`cd new-project`] и запустить команду `php artisan october:install`;
	4. Ответить на все вопросы в терминале, ввести нужные данные, в т.ч. название базы данных (созданной выше), имя созданного пользователя, лицензионный ключ и т.д.;
	5. После инсталляции произвести создание в базе данных всех нужных таблиц, введя команду `php artisan october:migrate`;
4. Если после установки решили поменять адрес страницы администратора, то сделать это нужно в файле `XAMPP/htdocs/NewProject/.env`^[раньше настройки располагались по адресу `XAMPP/htdocs/NewProject/config/backend.php`]. Установки конфигурации, действующие по умолчанию, находятся в файле `.env.example`;
5. Про перенастройку других конфигураций см. [[Параметры конфигурации]];
6. Инициализировать **git** и сохранить стартовый проект.
