
Основные правила [шаблонизации Twig внутри October CMS](https://docs.octobercms.com/3.x/markup/templating.html):
1. **Теги** (команды Twig) оборачиваются в фигурные скобки и процентные символы, например, команда `set`:
   
   ```twig
   {% set %}
   ```
   
2. Объявление переменной - через ключевое слово **set** в коде: 
   
   ```twig
   {% set my-variable = 'value'; %}
   ```
   
3. **Вывод переменных** - через двойные фигурные скобки: 
   
   ```twig
   {{ my-variable }}
   ```


4. **Конкатенация строк** через символ `~`: 
   
   ```twig
   {{ first-string ~ second-string }}
   ```
5. в ==October CMS== шаблонизатор также работает для скриптов JS. **Особености**:
	1. переменная должна быть зарегистрирована в PHP-блоке до использования в скриптах:
	   
		```php
		$this['post'] = $this->Content->post($this->param('slug'));
		```
	   
	2. можно использовать данную переменную в блоках Twig как обычную переменную:
	   
		```twig
		{% title = post.title %}
		```
	   
	3. скрипты должны быть локальными, а не внешними. Во внешних доступа к переменным не будет;	   
	4. переменная доступна внутри любой строки:
	   
		```js
		let promocode = localStorage.getItem('promocode-{{post.id}}');
		```
	   
	5. в случае, если переменная возвращает число, ее необязательно оборачивать в кавычки, но для строковых данных кавычки обязательны, иначе движок JS воспримет содержимое переменной как ярлык другой переменной:
	   
		```js
		let postId = {{ post.id }}; // post.id - число, ОК
		let postSlug = '{{ post.slug }}'; // post.slug - текст, только в кавычках!
		```
