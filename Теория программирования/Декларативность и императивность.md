Помимо HTML, еще один из примеров деклативного языка - SQL] | Императивная^[Это набор инструкций (команд), показывающих, КАК создать конкретные HTML-элементы. **Декларативность** - описание *схемы* того, что мы желаем получить, без погружения в технологии, как движок работает под капотом. Для языка HTML это html-разметка (теги языка, конструирующие структуру желаемого документа), для языка SQL это команды языка, описывающие структуру желаемых к получению данных. Во Vue технология Options API (классическое описание параметров js-скрипта в виде объекта с множеством полей) подразумевает также декларативный стиль. 
Декларативность предоставляет большее удобство разработчику и подразумевает **более высокоуровневый язык**, т.е. последующую переработку движком его команд в ==команды императивного стиля==.

**Императивность** - указание движку непосредственного набора команд для выполнения. Пример - любой язык программирования (тот же JavaScript), на котором пишутся конкретные команды для последующих компиляции и запуска. 
~~**Минусы**~~: более глубокое погружение в команды языка программирования. **Плюсы**: не содержит сюрпризов - т.е. выполняется строго то, что было написано. 
Кроме того, *показатель императивности относителен*: для Vue язык JavaScript императивен, а для Assembler он является декларативным.
