1. **CMS** - Content Management System - система управления содержимым. По сути - это конструктор сайтов, содержащий свои элементы, блоки, из которых можно собрать свой сайт. Пример - [MODX](https://modx3.com/documentation/obzor-modx), [October](https://octobercms.com/).
2. **PDO** - PHP Data Objects - расширение для PHP, предоставляющее разработчику универсальный интерфейс (единые методы) для доступа к различным базам данных. 
3. **ORM** - Object-Relational Mapping - технология, связывающая базу данных с ООП-языком программирования. Это позволяет выполнять операции CRUD с базой в рамках языковых классов, без прямого обращения к таблицам (вариант PDO). 4. **CRUD** - Create/Read/Update/Delete - операции с таблицами баз данных;
5. **API** - [Application Programming Interface](https://skillbox.ru/media/code/chto_takoe_api/) - способ связывания одной компьютерной программы с другой для обмена данными. Интерфейс - граница между двумя системами. Процессы в каждой системе изолированы друг от друга. Смысл API - с одной стороны отправляется запрос с определенными параметрами, в ответ от другой стороны возвращается информация в определенном виде. Как происходит процесс формирования результирующих данных во второй стороне, первую сторону не волнует. Примеры - REST API (веб-запросы), SOAP API и др.
6. HTTP-запросы:
	1. **REST API** - Representional State Transfer - получение и модификация данных путем формирования http-запроса через интернет или другую сеть. Обмен данными производится в виде передачи XML, JSON и др. форматов.
	2. **SOAP API** - Simple Object Access Protocol - веб-сервис для обмена сообщениями между клиентом и сервером по протоколу SOAP. Сообщения должны быть написаны строго на языке XML, иначе сервер вернет ошибку. В настоящее время устаревший, более популярным является REST API.
