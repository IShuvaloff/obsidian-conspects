#Реактивность #Синхронизация #Vue/ДвустороннееСвязывание 

**Реактивность** - способность системы реагировать на изменения данных и выполнять какую-либо логику (чаще всего обновление HTML). Это любые действия, которые производятся в системе в результате  изменения каких-либо данных.

Что включает система:
1. **Данные** - простая статическая информация;
2. **Состояние** - та или иная совокупность значений данных, которая изменится с течением времени. 

==Пример реактивности==:
1. Данные - например, значение фильтра;
2. Состояние - например, в пагинации, т.е. номер текущей страницы;
3. Действие - изменение значение фильтра;
4. Реактивность - автоматическое изменение состояние пагинации, т.е. сброс на 1-ю страницу.  

**Синхронизация** - операция, которая в противоположность реактивности вызывает синхронные изменения в данных после изменений в интерфейсе. На этом основан принцип *двустороннего связывания во Vue* - когда элемент интерфейса связан с данными в системе Vue таким образом, что изменение в системе приведет к обновлению данных в интерфейсе, и наоборот: смена данных на форме изменяет значения в системе.
