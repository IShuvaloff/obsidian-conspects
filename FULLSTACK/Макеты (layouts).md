#slot

**Макет** - возможность объединить несколько страниц какими-то общими показателями, например, стилистикой оформления, т.к. стиль макета будет являться родительским для стилей его страниц. По умолчанию используется единый макет `layouts/default.vue`. 

==Структура шаблона макета==:
```vue
<template>
	<div class="...">
		...
		<slot />
		...
	</div>
</template>
```

==Особенности==:
1. в шаблоне можно указать общие родительские классы (в *html*-блоке) и фрагменты поведения (в блоке *script*) для всех страниц, что будут в макете;
2. страницы будут размещаться вместо тега **`<slot />`**;
3. Чтобы система макетов работала корректно, в корневом файле `app.vue` следует разместить тег **NuxtLayout**, внутри которого будет находиться тег со страницей **[[Страницы (pages)|NuxtPage]]**:
	```vue
	<template>
	    <div>
	        <NuxtLayout>
	            <NuxtPage />
	        </NuxtLayout>
	    </div>
	</template>
	```
