# PHP минимум для чтения Laravel

## Зачем это нужно

Цель урока — не изучить PHP целиком, а понять конструкции, которые уже используются в реальном коде HelpMeIn, чтобы Laravel перестал выглядеть магией.

## Короткая карта

```
PHP class
│
├── namespace
├── extends
├── implements
├── traits
├── properties
├── methods
│
├── static
│   └── Class::method()
```

## Class, object и instance

`class` — описание типа; `object` и `instance` — конкретный экземпляр этого типа. `$this` внутри instance method указывает на текущий экземпляр.

```php
class User
{
    public string $name;

    public function rename(string $name): void
    {
        $this->name = $name;
    }
}
```

## `->` и `::`

```php
$request->user();     // работа с конкретным объектом
Request::capture();   // обращение через класс / static API
```

Static method не имеет `$this`, но может работать со static properties класса. Для чтения `User::all()` — это class-level API Eloquent; под капотом Eloquent делает больше, чем обычный PHP static method.

## Namespace, `use`, autoload

```php
namespace App\Http\Controllers;

use App\Models\User;
use App\Models\User as UserModel;
```

`namespace` задаёт namespace. `use App\Models\User` означает, что короткое имя `User` относится к `App\Models\User`; alias позволяет назвать его `UserModel`.

`use` не создаёт объект и не загружает данные из БД. Физический файл отдельно находит Composer autoload по PSR-4.

## Наследование, interface и trait

```php
class User extends Authenticatable implements PasskeyUser
{
    use HasFactory;
    use Notifiable;
}
```

| Конструкция | Смысл |
|---|---|
| `extends` | Наследование от одного класса. |
| `implements` | Соблюдение контракта интерфейса. |
| `use Trait` | Добавление повторно используемого поведения. |

Trait может обращаться к `$this` и состоянию объекта класса, в который он подключён:

```php
trait HasFullName
{
    public function getFullName(): string
    {
        return trim($this->name . ' ' . $this->surname);
    }
}
```

Например, `use Notifiable;` добавляет модели Laravel поведение уведомлений.

## Visibility и типы

| Visibility | Доступ |
|---|---|
| `public` | Отовсюду. |
| `protected` | Внутри класса и наследников. |
| `private` | Только внутри самого класса. |

Это runtime visibility ООП, а не TypeScript type system.

```php
public function handle(Request $request): Response
```

`Request $request` — type hint параметра, `: Response` — return type. В `function configure(): void` `void` означает, что функция не возвращает содержательное значение.

`?User` и `User|null` по смыслу эквивалентны. Union type допускает несколько типов: `User|Client|null`.

## PHP arrays

Indexed и associative arrays в PHP — не разные runtime types, а два способа использовать один `array`.

```php
[10, 20, 30];

[
    'name' => 'Ilya',
    'age' => 38,
];
```

```php
$user['name'];
$user['age'] = 39;
$user['email'] = 'test@example.com';
isset($user['email']);
```

Spread объединяет элементы массива:

```php
[
    ...parent::share($request),
    'name' => config('app.name'),
]
```

## Closures, callbacks и arrow functions

`function (...) {}` — anonymous function / closure. Closure можно передать как значение другой функции; callback — функция, переданная для вызова позже.

```php
withMiddleware(function (Middleware $middleware): void {
    // ...
});
```

Arrow function автоматически захватывает внешнюю переменную по значению:

```php
$factor = 10;
$multiply = fn ($x) => $x * $factor;
```

Обычной anonymous function обычно нужен явный захват:

```php
$factor = 10;
$multiply = function ($x) use ($factor) {
    return $x * $factor;
};
```

В JavaScript lexical scope позволяет обычной функции автоматически видеть внешние переменные; в PHP обычной anonymous function для этого обычно нужен `use (...)`.

## Magic methods, named arguments, `??` и `?->`

`__construct()` вызывается при создании объекта. `__invoke()` делает объект callable — поэтому в HelpMeIn controller может выглядеть так:

```php
class ClientController extends Controller
{
    public function __invoke()
    {
        // ...
    }
}
```

```php
Application::configure(
    basePath: dirname(__DIR__)
)
```

`basePath:` — named argument.

```php
$request->cookie('appearance') ?? 'system';
$user?->name;
```

`??` использует `'system'`, если значение слева `null`. Это можно держать в голове рядом с Oracle `NVL()`, но это не идентичный механизм. `?->` получает `name`, если `$user` не `null`; иначе возвращает `null` (по смыслу как `user?.name` в JavaScript).

## Dependency Injection — базовый уровень

Dependency Injection — объект или метод не создаёт нужную ему зависимость сам, а получает её извне.

```php
// Без DI
class OrderController
{
    public function store()
    {
        $paymentService = new PaymentService();
    }
}

// С DI
class OrderController
{
    public function __construct(
        private PaymentService $paymentService
    ) {
    }
}
```

Laravel может автоматически разрешить зависимость через Service Container. В `public function __invoke(Request $request)` framework видит type hint и передаёт текущий `Request` как обычный аргумент; это не поиск переменной в global scope.

## Eloquent casts — не TypeScript types

```php
protected function casts(): array
{
    return [
        'is_admin' => 'boolean',
        'email_verified_at' => 'datetime',
        'password' => 'hashed',
    ];
}
```

Eloquent cast — runtime transformation значения атрибута при чтении и записи модели:

```text
DB value → Eloquent cast → PHP value/object
is_admin: 1 → boolean → true
```

TypeScript type даёт статическую проверку до runtime; Eloquent cast реально преобразует значение в runtime.

## Цельный разбор `ClientController`

```php
namespace App\Http\Controllers;

use App\Models\User;

class ClientController extends Controller
{
    public function __invoke()
    {
        $users = User::all();

        return inertia('Clients', [
            'users' => $users,
        ]);
    }
}
```

- `namespace` задаёт пространство имён controller.
- `use` импортирует короткое имя модели `User`.
- `extends` наследует базовое поведение `Controller`.
- `public method` доступен framework.
- `__invoke` делает экземпляр controller callable для route.
- `User::all()` — class-level API Eloquent для чтения моделей.
- `$users` хранит полученную коллекцию.
- `['users' => $users]` — associative array props.
- `return` возвращает Inertia response для Vue page `Clients`.

## Цельный разбор middleware

```php
public function handle(
    Request $request,
    Closure $next
): Response {
    View::share(
        'appearance',
        $request->cookie('appearance') ?? 'system'
    );

    return $next($request);
}
```

- `Request` и `Closure` — type hints; Laravel передаёт текущий Request как dependency.
- `Closure $next` — callback для передачи request следующему слою pipeline.
- `: Response` — return type.
- `View::share` использует class/static API (`::`).
- `$request->cookie(...)` вызывает method конкретного объекта (`->`).
- `??` задаёт значение по умолчанию.
- `$next($request)` передаёт request дальше и возвращает полученный Response.

## Границы и краткое резюме

| Конструкция | Как читать в Laravel |
|---|---|
| `->` | Вызов на конкретном объекте. |
| `::` | Class/static API. |
| `use` | Короткое имя класса, не создание объекта. |
| `extends` / `implements` / trait | Базовый класс / контракт / примесь поведения. |
| Type hint | Подсказка и проверяемое ограничение типа в PHP runtime. |
| DI | Нужный объект передаётся извне. |
| Eloquent cast | Runtime-преобразование атрибута модели. |

Формулировка для повторения: **Laravel-код — это обычный PHP, где framework связывает type hints, middleware callbacks, Eloquent API и Inertia response в обработку HTTP use case.**

## Для проверки знаний

### Термины

- Class, object / instance, `$this`, instance method и static API.
- Namespace, `use`, Composer autoload, PSR-4.
- `extends`, `implements`, trait, visibility, type hint, nullable и union type.
- Closure, callback, `__construct`, `__invoke`, Dependency Injection, Eloquent cast.

### Что нужно уметь объяснить

- Различие между `$request->user()` и `Request::capture()`: объектный вызов против class/static API.
- Почему `use App\Models\User` задаёт короткое имя, но не создаёт объект, не запрашивает БД и не загружает файл самостоятельно.
- Как Laravel передаёт `Request $request` в controller и почему это Dependency Injection, а не поиск переменной в global scope.
- Чем Eloquent cast отличается от TypeScript type: преобразование значения в runtime против статической проверки.

### Типичные ошибки

- Называть `User::all()` просто static method без оговорки, что это class-level API Eloquent.
- Считать `protected` TypeScript-типом либо trait отдельным объектом без доступа к `$this`.
- Ожидать, что обычная PHP anonymous function автоматически захватит внешнюю переменную без `use (...)`.
- Считать TypeScript type защитой от некорректного значения, пришедшего из БД или HTTP response в runtime.

### Мини-практика

- Найди и объясни ошибку в коде: `function ($x) { return $x * $factor; }`. Как передать `$factor` в closure и чем эта запись отличается от `fn ($x) => $x * $factor`?
- МикроТЗ: дополни invokable controller так, чтобы он принял `Request $request`, получил текущего пользователя через `$request->user()` и передал его в `inertia(...)` как associative array. Критерии: есть type hint, object call через `->`, корректный `return` и нет ручного `new Request()`.
