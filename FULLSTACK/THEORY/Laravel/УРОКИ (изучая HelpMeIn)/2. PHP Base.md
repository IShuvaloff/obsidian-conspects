
## Класс PHP

```
PHP class
│
├── namespace
├── extends
├── implements
├── traits
├── properties
├── methods
│
├── static
│   └── Class::method()
│
└── instance
    └── $object->method()
```

```
Laravel
│
├── type hints
├── dependency injection
├── closures
├── callbacks
├── magic methods
├── traits
└── framework classes
```

## Термины

|Термин|Коротко|
|---|---|
|Class|Описание типа объектов|
|Object|Экземпляр класса|
|Instance|То же: экземпляр|
|Namespace|Полное логическое пространство имени|
|Import|`use` имени класса|
|Inheritance|`extends`|
|Interface|Контракт|
|Trait|Повторно используемое поведение|
|Visibility|`public/protected/private`|
|Static method|Метод класса|
|Instance method|Метод объекта|
|Type hint|Ограничение/описание типа|
|Nullable|Может быть `null`|
|Union type|Несколько допустимых типов|
|Closure|Анонимная функция|
|Callback|Функция, переданная для вызова позже|
|Magic method|Специальный `__method`|
|Dependency Injection|Передача зависимостей извне|
|Service Container|Laravel-механизм создания/разрешения зависимостей|
