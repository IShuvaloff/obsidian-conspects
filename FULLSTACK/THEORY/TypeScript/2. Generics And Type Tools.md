# TypeScript Generics & Type Tools

## 1. Generics

С `any`:

```ts
function identity(value: any): any {
  return value
}
```

Типовая информация теряется.

С generic:

```ts
function identity<T>(value: T): T {
  return value
}

const result = identity('hello')
// string
```

Главная идея:

> Generic позволяет писать универсальный код, сохраняя связь между конкретными типами входов и выходов.

---

## 2. Несколько generic-параметров

```ts
function pair<T, U>(first: T, second: U): [T, U] {
  return [first, second]
}

const result = pair('age', 42)
// [string, number]
```

---

## 3. Generic Constraints и `extends`

```ts
interface HasLength {
  length: number
}

function getLength<T extends HasLength>(value: T): number {
  return value.length
}
```

`T extends SomeType` означает: `T` должен быть совместим с `SomeType`.

Контексты `extends`:

```ts
interface Admin extends User
T extends object
K extends keyof T
T extends string ? A : B
```

---

## 4. Связь ключа и значения

```ts
function updateField<T, K extends keyof T>(
  object: T,
  key: K,
  value: T[K]
) {
  object[key] = value
}
```

```ts
const user = {
  id: 1,
  name: 'Alex',
  active: true
}
```

Работает:

```ts
updateField(user, 'name', 'Bob')
```

Ошибки:

```ts
updateField(user, 'name', 123)
updateField(user, 'age', 30)
```

`K extends keyof T` ограничивает ключи, а `T[K]` связывает value с выбранным key.

## 5. `keyof`

```ts
interface User {
  id: number
  name: string
  active: boolean
}

type UserKeys = keyof User
```

Результат:

```ts
'id' | 'name' | 'active'
```

## 6. `typeof` в TypeScript

Runtime:

```ts
if (typeof value === 'string') {
}
```

Type position:

```ts
const user = {
  id: 1,
  name: 'Alex'
}

type User = typeof user
```

Формула:

```text
JS typeof value -> runtime-проверка
TS typeof value в type position -> извлечение статического типа
```

## 7. Три очень полезных паттерна без дублирования

### 7.1. Union literal-значений из массива

```ts
const statuses = [
  'loading',
  'success',
  'error'
] as const

type Status = typeof statuses[number]
```

Результат:

```ts
'loading' | 'success' | 'error'
```

Runtime-массив становится source of truth и для TypeScript-типа.

### 7.2. Union ключей runtime-объекта

```ts
const roles = {
  admin: 'Administrator',
  user: 'User',
  guest: 'Guest'
}

type Role = keyof typeof roles
```

Результат:

```ts
'admin' | 'user' | 'guest'
```

### 7.3. Union значений runtime-объекта

```ts
const permissions = {
  admin: 100,
  editor: 50,
  viewer: 10
} as const

type PermissionLevel =
  (typeof permissions)[keyof typeof permissions]
```

Результат:

```ts
100 | 50 | 10
```

### Сравнение

| Задача | Конструкция |
|---|---|
| Union значений массива | `typeof arr[number]` + `as const` |
| Union ключей объекта | `keyof typeof obj` |
| Union значений объекта | `(typeof obj)[keyof typeof obj]` |

## 8. Indexed Access Types

```ts
type NameType = User['name']
// string
```

```ts
type UserValues = User[keyof User]
// number | string | boolean
```

Формула:

```text
T[K] -> тип значения по ключу K
T[keyof T] -> union типов всех значений объекта
```

---

## 9. `as const`

Без `as const`:

```ts
const statuses = ['loading', 'success', 'error']
// string[]
```

С `as const`:

```ts
const statuses = ['loading', 'success', 'error'] as const
// readonly ['loading', 'success', 'error']
```

`as const`:

1. сохраняет literal types;
2. делает структуру readonly.

## 10. Utility Types

### `Partial<T>`

Все свойства optional.

```ts
const patch: Partial<User> = {
  name: 'Bob'
}
```

Полезно для update/PATCH model.

### `Pick<T, K>`

Оставляет только перечисленные свойства.

```ts
type UserPreview = Pick<User, 'id' | 'name'>
```

`Pick` не делает поля optional.

Композиция:

```ts
Partial<Pick<User, 'id' | 'name'>>
```

### `Omit<T, K>`

Удаляет перечисленные поля.

```ts
type PublicUser = Omit<User, 'email'>
```

### `Readonly<T>`

Делает свойства readonly. Стандартный `Readonly<T>` — shallow.

### `Record<K, V>`

Объект-словарь:

```ts
type UsersById = Record<string, User>
```

Это не массив.

### `Exclude<T, U>`

Удаляет варианты из union.

### `Extract<T, U>`

Оставляет только совпадающие варианты union.

### `NonNullable<T>`

Удаляет `null` и `undefined`.

### `ReturnType<T>`

Извлекает возвращаемый тип функции.

### `Parameters<T>`

Извлекает параметры функции как tuple.

```ts
function createUser(id: number, name: string) {
  return { id, name, active: true }
}

type Args = Parameters<typeof createUser>
// [number, string]
```

## 11. Mapped Types

Mapped type программно строит новый тип из свойств другого.

```ts
type Something<T> = {
  [K in keyof T]: ...
}
```

### Самодельный `Partial`

```ts
type Optional<T> = {
  [K in keyof T]?: T[K]
}
```

`Optional` — кастомное учебное имя.

### `Nullable<T>`

```ts
type Nullable<T> = {
  [K in keyof T]: T[K] | null
}
```

### Feature Flags

```ts
type FeatureFlags<T> = {
  [K in keyof T]: boolean
}
```

### Getters

```ts
type Getters<T> = {
  [K in keyof T]: () => T[K]
}
```

### Ошибки формы

```ts
type FormErrors<T> = {
  [K in keyof T]?: string
}
```

Практический frontend-use case:

```ts
interface UserForm {
  name: string
  email: string
  age: number
}

const errors: FormErrors<UserForm> = {
  email: 'Некорректный email'
}
```

### Mapped tuple

```ts
type ToPromises<T extends readonly unknown[]> = {
  [K in keyof T]: Promise<T[K]>
}

type Values = [string, number, boolean]
type Result = ToPromises<Values>
```

Результат:

```ts
[
  Promise<string>,
  Promise<number>,
  Promise<boolean>
]
```

## 12. Conditional Types

Шаблон:

```ts
T extends U ? X : Y
```

Учебный пример:

```ts
type IsString<T> =
  T extends string ? true : false
```

`IsString` — кастомный conditional type, не встроенная функция.

Практичный пример:

```ts
type MyNonNullable<T> =
  T extends null | undefined
    ? never
    : T
```

## Быстрая interview-шпаргалка

```text
Generic -> универсальный код без потери связи типов
T extends X -> T совместим с X
keyof T -> union ключей
typeof value -> тип существующего значения
T[K] -> тип свойства
T[keyof T] -> union типов значений
Mapped type -> преобразует свойства типа
Conditional type -> выбирает тип по условию
```
