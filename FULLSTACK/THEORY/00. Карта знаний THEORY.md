# Карта знаний THEORY

> [!summary]
> Эта страница — навигатор, а не ещё один учебник. Она связывает конспекты в одну траекторию: язык → frontend → backend → данные/API → качество → delivery. Подробности живут в тематических файлах.

## Текущий маршрут

```text
JavaScript + TypeScript
            ↓
Vue 3 + Nuxt 3 ────────┐
            ↓           │
Laravel + PostgreSQL ───┼──→ API / внешние интеграции / realtime
            ↓           │
Тестирование + CI ──────┘
            ↓
Docker + Linux + NGINX + CI/CD
```

Текущий подробный порядок: [[ПЛАНЫ ИЗУЧЕНИЯ]].

## Правила поддержания карты

1. Новая подробная глава получает ссылку из этой карты и ссылку на свои предпосылки.
2. Большая тема получает краткое summary для повторения.
3. После переименования файла или заголовка проверяются ссылки.
4. Если тема нужна позже, ставится `TODO: углубить` и ссылка вместо перегрузки текущей главы.
5. Стандарт объяснения и проверки знания зафиксирован в `ИНСТРУКЦИЯ ДЛЯ AI-НАСТАВНИКА.md`.
