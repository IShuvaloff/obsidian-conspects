#favicon #nuxt-config 

Порядок работы:
1. выбрать исходное svg-изображение в качестве иконки для сайта (табов в браузере, ярлыков на рабочем столе, ссылок и т.д.);
2. на ресурсе [RealFaviconGenerator](https://realfavicongenerator.net/) создать пакет с различными иконами и линками для их вставки на сайт - порядок действий:
	1. зайти на страницу, нажать главную кнопку и выбрать нужный файл:
	   
	   ![[Pasted image 20240215201001.png]]
	   
	2. проверить подобранные цвета для разных форматов и устройств, требуется проматывать вниз и проверять каждое устройство:
	   
	   ![[Pasted image 20240215200913.png]]
	   
	3. задать финальную директорию (при необходимости), где будут размещены иконки:
	   
	   ![[Pasted image 20240215201100.png]]
	   
	4. получить соответствующие адреса для вставки в `<head>` и скачать пакет с файлами:
   
	   ![[Pasted image 20240215201158.png]]
	   ![[Pasted image 20240215201246.png]]
   
3. Разместить полученные файлы в папку с иконками (например, `/public/favicon`) в публичной директории сайта:
   
   ![[Pasted image 20240215201633.png|300]]
   
4. В файле `nuxt.config.ts` добавить свойство `app` с заголовком `head` внутри, и далее разместить в нем 2 объекта - метаданные `meta` и ссылки `link`, аналогично тому, как это было предложено на сайте (см. п.2.4) с тем отличием, что на сайте предложили статичные ссылки для html-страницы, а нам нужно переделать их в объекты с одноименными полями:
   
   ![[Pasted image 20240215202015.png|400]]

5. при внесении изменений в конфигурационные данные следует перезапустить проект на всякий случай, несмотря на его автоматическую пересборку (могут быть глюки).
