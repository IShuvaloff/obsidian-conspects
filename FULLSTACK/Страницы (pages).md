В Nuxt.js нет необходимости создавать свои маршруты (routes). Вместо это используется директория `/pages` - [готовые страницы](https://nuxt.com/docs/getting-started/routing). Маршруты создаются на каждую из созданных страниц автоматически. 

==Чтобы система маршрутизации работала==, требуется в главном файле `app.vue` в корневой папке приложения добавить систему тегов **[[Макеты (layouts)|NuxtLayout]]** и **NuxtPage**:
```html
<template>
    <div>
        <NuxtLayout>
            <NuxtPage />
        </NuxtLayout>
    </div>
</template>
```

**ВАЖНО**: 
1. все страницы по умолчанию привязаны к [[Макеты (layouts)|макету]] `layouts/default.vue`. Чтобы привязать созданную страницу к другому макету, требуется в скрипте страницы вызвать функцию definePageMeta с указанием свойства *layout*, равного названию требуемого макета (см. в [[Утилиты Nuxt.js (utils)|утилитах Nuxt.js]]);
2. по умолчанию навигация между страницами происходит в связке только с глобальным [[Промежуточное ПО (middleware) TODO!|промежуточным ПО]] (middleware). Для того, чтобы привязать локальный middleware к определенной странице, нужно также прописать в definePageMeta свойство *middleware* равное названию требуемого ПО (см. в [[Утилиты Nuxt.js (utils)|утилитах Nuxt.js]]);
3. Дополнительно про регистрацию новых страниц через модули читай в [[Модули (modules)|модулях Nuxt]].

### Особенности перехода по страницам

Правило | Расположение файла | Адрес страницы
--: | -- | --
Главная страница в папке | `pages/index.vue` | http://localhost:3000/
Остальные страницы в папке | `pages/page.vue` | http://localhost:3000/page/
Главная страница во вложенной папке | `pages/folder/index.vue` | http://localhost:3000/folder/
Остальные страницы во вложенной папке | `pages/folder/another.vue` | http://localhost:3000/folder/another
Несколько уровней вложений | `pages/folder/subfolder/new-page.vue` | http://localhost:3000/folder/subfolder/new-page/
==**Динамическое имя страницы**==<br>(например,<br>`id = 12`) | `pages/folder/[id].vue`<br>(имя файла: *"[id].vue"*) | http://localhost:3000/folder/==**12**==

### Ручной переход по маршрутам

1. для КНОПОК и ССЫЛОК - с помощью атрибута **`:to`**, принимающего объект с именем и параметрами (о параметрах читай [[Модули (modules)|здесь в п.6]]):

	```html
	<BaseButton :to="{ name: 'otdyhayshim-chem-zanyatsya', params: {} }">
		Все активности
	</BaseButton>
	```

	* если все страницы находятся в папке `/pages`, то нет необходимости добавлять расширения страниц в модули, т.к. они автоматически добавляются в базу компонентов Nuxt;
	* если в папке `/pages` имеются подпапки, то имена страниц, необходимые для ручного перехода по ссылкам, формируются через соединение имен всех вложенных папок и конечного файла через дефис;
	* параметр, требуемый для открытия страницы, носит название страницы в квадратных скобках (например, страница `[slug].vue`, параметр для перехода - `slug: ...`):
	  
	  ![[Pasted image 20240212092446.png|300]]
	  
	  ```html
	  <BaseButton :to={ name: 'projects-slug', params: { slug: 'project1' } }>
			Перейти к проекту
		</BaseButton>
		```

	* в случае размещения страниц в другом, отличном от системной папки, месте, требуется расширить базу страниц через использование модуля `defineModule` и процедуры `extendPages` (см.  [[Модули (modules)|здесь в п.6]]);
2. для БЛОКОВ - с помощью обработчика `@click`, принимающего вызов функции **`navigateTo`** с именем и параметрами вызова внутри:

	```html
	<div @click="navigateTo('otdyhayshim-chem-zanyatsya', {})">
		Все активности
	</div>
	```
