#navigateTo #global #middleware

Если необходимо при смене старого сайта на новый сохранить возможность перехода по старым ссылкам/маршрутам, можно реализовать это простым путем:
1. создание файла *.json* с объектом, в котором будут расположены относительные URL старого сайта в качестве ключей и соответствующие им новые URL в качестве значений:
   
```json
{
    "/login": "/?login=1",
    "/lichnuy-kabinet": "/lk",
    "/contacts": "/feedback",
    "/konfidencialnaya-informaciya": "/privacy",
}
```
   
2. добавление глобального миддлвара для выполнения редиректа - осуществляем поиск целевого маршрута (`to`) в JSON-объекте из предыдущего файла. При наличии делаем `navigateTo` с указанием кода редиректа:

```ts
import redirects from "./redirects.json";
export default defineNuxtRouteMiddleware(async (to) => {
    const redirectUrl = redirects[to.path as keyof typeof redirects];
    if (redirectUrl) {
        return navigateTo(redirectUrl, { redirectCode: 301, external: redirectUrl.startsWith("http") });
    }
    return;
});
```
