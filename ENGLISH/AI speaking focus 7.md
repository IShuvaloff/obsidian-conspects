# 4. Listening Strategy

| Step | Strategy |
|---|---|
| 1 | Catch the main event. |
| 2 | Notice key verbs and nouns. |
| 3 | Do not stop mentally at one unknown word. |
| 4 | Ask for clarification only when the missing phrase blocks the meaning. |
| 5 | Re-listen to difficult phrases. |
| 6 | Learn the phrase as a chunk. |

The next listening exercises should gradually become longer:

- next lesson: around **5–7 sentences**;
- later: around **1–1.5 minutes**;
- after that: around **3 minutes**.

# 5. Wait vs. Expect

| Word | Core Meaning | Example |
|---|---|---|
| **wait** | stay until something happens | **I waited for the bus for twenty minutes.** |
| **expect** | believe or think something will happen | **I expected the bus to arrive at five.** |

Useful patterns:

- **wait for + noun**
- **expect + noun**
- **expect + person + to + verb**

Examples:

- **I waited for my friend.**
- **I expected a reply.**
- **I expected him to call.**

---

# 6. Go Further vs. Continue

| Phrase | Meaning | Example |
|---|---|---|
| **continue** | keep doing the current activity | **Let’s continue with the lesson.** |
| **go further** | move deeper into a subject | **Can you go further into detail?** |

For a lesson:

**Let’s continue.**

For deeper explanation:

**Let’s go further into this topic.**

# 7. Grammar — Used To vs. Be Used To

## A. Used To

**used to + base verb**

Meaning: a past habit or situation that is no longer true.

| Structure | Example |
|---|---|
| **used to + base verb** | **I used to play tennis.** |
| | **We used to go there every summer.** |
| | **I used to work in an office.** |

Important:

**used to go** ✅  
**used to going** ❌

## B. Be Used To

**be used to + noun / -ing**

Meaning: something is normal or familiar to you now.

| Structure | Example |
|---|---|
| **be used to + noun** | **I'm used to this weather.** |
| **be used to + -ing** | **I'm used to working late.** |
| | **I'm used to getting up early.** |
| | **I'm used to doing this.** |

Important:

**I'm used to working late.** ✅  
**I'm used to work late.** ❌

## C. Present Routine

For something you regularly do now, use the **present simple**.

| Meaning | Example |
|---|---|
| current routine | **I usually wake up at eight.** |
| current routine | **I have breakfast around ten.** |
| current routine | **My wife and I usually go for a walk in the evening.** |

# Final Reflection

Lesson 7 became much closer to the intended course format.

The strongest parts were the moments when the conversation moved away from isolated grammar drills and into genuine spontaneous English:

- explaining personal experiences;
- listening to short stories;
- discussing a difficult English book;
- talking about Nobel and Snowden;
- discussing homeland, migration, identity, and belonging.

The biggest methodological conclusion is clear:

> Fluency grows best here when the lesson contains variety, surprise, deeper topics, natural listening, and enough space for long answers.

Grammar should remain part of the course, but it should support conversation rather than dominate it.
