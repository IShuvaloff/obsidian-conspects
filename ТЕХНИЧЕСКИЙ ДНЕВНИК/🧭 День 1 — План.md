### 💻 Практика

#### 1. **Модуль в JS (ES6)**

js

```
// user.js
export const createUser = (name) => ({
    getName: () => name,
    setName: (newName) => name = newName
});
```

#### 2. **Фабрика в Vue**

js

```
// composables/useUserFactory.js
export const useUserFactory = () => {
    const createUser = (name, role) => ({
        name,
        role,
        describe: () => `${name} работает как ${role}`
    });
    return { createUser };
};
```

#### 3. **Мини-проект**

- Создай компонент `<UserCard>` с фабрикой создания пользователя
    
- Вынеси логику в Composable (модуль)
    
- Используй `ref`, `computed`, `defineExpose`
