**Утилиты** - функции, которые необязательно импортировать и можно использовать в любом месте в приложении. Должны размещаться в корневой папке `utils/` и экспортироваться по умолчанию (в этом случае название файла будет названием функции), либо стандартным способом с указанием названия функции в файле. 

Системные утилиты:
1. **[definePageMeta](https://nuxt.com/docs/api/utils/define-page-meta)** - функция, используемая в инициализаторе *setup* страницы, которая позволяет переопределить страничные мета-данные ==перед рендерингом страницы==, в т.ч.:
	* **принадлежность к определенному макету** (layout):
		```ts
		definePageMeta({
			layout: 'custom-layout',
		})
		```
	* **привязка к промежуточному ПО** (middleware):
		```ts
		definePageMeta({
			// можно указывать также массив миддлваров, выполняться будут по порядку
			middleware: 'auth',
		})
		```
	* **кастомные данные**, которые будут доступны в любом месте страницы:

		```ts
		definePageMeta({
			coloredLogo: true,
		})
		```

		Доступ к мета-информации страницы возможен через композабл [[Композаблы Nuxt.js (composables)|useRoute()]]: **`useRoute().meta.coloredLogo`**
