#body-scroll-lock #vue-final-modal #splidejs

1. **`body-scroll-lock`** - блокировка пролистывания главной страницы на фоне пролистываемых блоков. Требует установки 2 плагинов:
	1. установка плагина `npm i body-scroll-lock`;
	2. добавление типов данных для плагина `npm i -D @types/body-scroll-lock`;
	3. создание внутреннего плагина в файле `src/plugins/body-scroll-lock.ts`:
	   
	   ![[Pasted image 20240110115752.png]]
2. **`v-body-scroll-lock`** - альтернатива предыдущему плагину, готовая директива (без необходимости ее создавать, как в п.1, см. скрин);

3. **`splidejs`**;
4. **`vue-final-modal`** - универсальное модальное окно проекта, см. [[Плагины (plugins)|здесь]]. ==ВАЖНО==: нет необходимости устанавливать `body-scroll-lock`, если она требуется только для работы с модальным окном;
5. **`style-resources`** - [плагин для **Nuxt 2**](https://www.npmjs.com/package/@nuxtjs/style-resources) и работе с препроцессорами Sass/Less/Stylus - позволяет автоматически подключать файлы с общими данными, которые требуются в большинстве компонентов, например, файлы с переменными (для Sass это обычно файлы `/scss/_variables.scss` либо формата sass). В этом случае нет необходимости в стилях каждого компонента производить импорт этих файлов. *Полезно при создании новых компонентов/страниц*.
