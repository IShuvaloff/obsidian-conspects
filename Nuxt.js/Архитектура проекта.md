
1. `assets/` и `public/` - [[Вложения (public и assets)|файлы проекта]];
2. `components/` - список Vue-компонентов, формирующих строительные элементы приложения;
3. `interfaces/` - интерфейсы TypeScript;
4. `composables/` и `utils/` - [[Композаблы Nuxt.js (composables)|вспомогательные функции]] и [[Утилиты Nuxt.js (utils)|утилиты Nuxt.js]];
5. `layouts/` - [[Макеты (layouts)|макеты страниц]];
6. `modules/` - [[Модули (modules)|модули приложения]] (нужно иметь в виду, что каждый модуль может иметь ту же архитектуру, что и архитектура проекта в целом);
7. `pages/` - [[Страницы (pages)|отдельные страницы]];
8. `plugins/` - [[Плагины (plugins)|подключаемые плагины]];
9. `middleware/` - [[Промежуточное ПО (middleware) TODO!|промежуточное ПО]];
10. `store/` - [[Хранилище данных (useStates vs. Pinia)|работа с хранилищем данных]];
11. `services/` файлы js/ts, представляющие различные сервисы для работы приложения, например, функции загрузки данных по API-запросам. Располагаются как в корневой директории или общей модульной директории `modules/services/` (если это общие утилиты для всех модулей), так и непосредственно внутри модулей `modules/module1/services/`;
12. `utils/` - разнообразные js/ts-утилиты для обработки, форматирования, преобразования данных. Особенности:
	1. располагаются **только** в корневой папке проекта;
	2. представляют из себя файлы js/ts;
	3. *не требуют последующего импорта* во всем приложении; 
	4. один файл - это одна функция, экспортируемая по умолчанию (`export default function(...params) {...}`);
	5. наименование файла должно быть в стиле `camelCase`;
	6. название функции в приложении будет равно названию файла без расширения;
13. `server/` - функционал бэкенда с возможностью быстрого формирования api-адресов для GET/POST и других запросов - [[Серверная часть (server)]];
