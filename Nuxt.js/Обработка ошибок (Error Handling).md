## Генерация ошибок Nuxt
2 способа генерации ошибок:
1. стандартными средствами JS (в этом случае можно добавить только текстовое поле):
   
```ts
throw new Error('новая ошибка');
```
   
2. [средствами Nuxt.js](https://nuxt.com/docs/api/utils/create-error) (создается объект, включающий в себя как поля стандартной ошибки JS, так и новые поля):
   
	```ts
	throw createError({
		statusCode: 401, 
		message: 'фатальная ошибка', 
		fatal: true,
	})
	```

	Особенности:
	* если не стоит `fatal: true`, поведение функции различается между SSR и CSR: на сервере идет переход на страницу с ошибкой, на клиенте просто генерируется ошибка в консоли, URL меняется, но страница не перерисовывается (остается прежней);
	* для уверенного перехода на страницу ошибки всегда следует выставить параметр `fatal: true` либо использовать аналогичную и более простую функцию вызова страницы с ошибкой `showError({...})`, включающую те же параметры, что и `createError({...})`.
