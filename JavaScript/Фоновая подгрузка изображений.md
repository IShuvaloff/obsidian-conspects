#img #image

Можно загружать изображения в фоне, чтобы:
1. не заставлять пользователя долго ждать рендеринга, показывая что-то другое, например, цвет, текст или что-то еще;
2. не показывать в случае ошибки загрузки иконку "ошибки" в углу контейнера с изображением.

==Порядок==:
1. создаем ссылку на элемент в DOM (в Nuxt это просто привязка тега `ref` к контейнеру);
2. добавляем флаг успешной/неуспешной загрузки (при ошибке не добавляем в контейнер новый элемент);
3. в хуке `mounted`/`onMounted` создаем объект `new Image()`;
4. приписываем объекту теги `src` и `alt`;
5. вешаем на объект обработчик `onload`, внутри которого: 
	* либо ==добавляем созданный объект в контейнер в DOM-дереве==;
	* ~~либо добавляем фон для контейнера с использованием полученной ссылки созданного объекта~~ (*это дичь какая-то: объект уже создан, а мы хватаем из него только ссылку???*)

```js
// замена сплошного фона изображением по факту корректной загрузки, добавление размытия

const imgLoaded = ref(false);
const img = ref<HTMLDivElement>();

onMounted(() => {
    if (!props.card.poster?.path) return;

    const image = new Image();
    image.alt = props.card.poster.title;
    image.src = props.card.poster.path;

    image.onload = () => {
        if (!img.value) return;
        img.value.style.backgroundImage = `url(${image.src})`;
        imgLoaded.value = true;
    };
});
```
