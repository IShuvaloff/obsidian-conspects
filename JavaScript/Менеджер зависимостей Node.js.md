#nodejs #npm #nvm

Node.js позволяет использовать команду **`npm`** - для установки различных плагинов в проект из [библиотеки npm](https://www.npmjs.com/). Установка и использование:
1. последней стабильной версии с сайта [Node.js](https://nodejs.org/en);
2. устанавливать рекомендуется *четные* версии программы:
   
   ![[Pasted image 20240130191852.png]]
   
3. можно установить конкретную версию программы из [предшествующих версий](https://nodejs.org/en/about/previous-releases);
4. установка новых плагинов в проект: `npm install ...`/`npm i -D ...` (для режима работы только в режиме разработки);
5. удаление плагинов из проекта: `npm remove ...`;
6. запуск проекта `npm run ...` (конкретная сборка указывается в файле `package.json`)

Если требуется работать в нескольких версиях Node.js для различных проектов^[например, для работы [[Nuxt.js/ПОЛЕЗНЫЕ ДАННЫЕ|Nuxt 2]] требуется верия Node.js 14 либо 16], нужно установить ==[менеджер переключения версий](https://github.com/coreybutler/nvm-windows?tab=readme-ov-file#installation--upgrades)== **`nvm`**. Установка и использование:
1. скачать по [ссылке](https://github.com/coreybutler/nvm-windows/releases) exe-версию установочника;
2. **удалить прежде установленный пакет Node.js**;
3. использовать [различные команды](https://github.com/coreybutler/nvm-windows/releases) установки/удаления версий Node.js:
	* `nvm install latest` - установить последнюю актуальную версию;
	* `nvm install 16` - установить последнюю версию из 16-й серии;
	* `nvm uninstall 16` - удалить 16-ю версию;
4. подключать (глобально) для текущей работы нужную версию Node.js:
	* `nvm use ...` - подключить требуемую версию.
