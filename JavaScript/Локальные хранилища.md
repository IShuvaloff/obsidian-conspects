#localStorage #sessionStorage

Создание [локального хранилища](https://learn.javascript.ru/localstorage) позволяет в рамках сессии хранить значения переменных, доступные в любой части сайта, в виде пар **"ключ-значение"**. 
1. `localStorage` - хранилище браузера, хранящее значения даже после перезагрузки окна;
2. `sessionStorage` - хранилище браузера, хранящее значения в рамках сессии (до перезагрузки окна).

==Отличие от куков==:
1. они не передаются на сервер при каждом запросе и поэтому могут вмещать значительно больше данных (от 5 Мб);
2. управляются только средствами JavaScript (нельзя управлять http-заголовками);
3. хранилища привязаны к домену/протоколу/порту. Следовательно, для каждого сайта обособлено свое хранилище данных.

==Данные localStorage можно поменять в терминале браузера==:
1. ввести команду `localStorage`;
2. выбрать конкретное хранилище, ввести `localStorage.storeName`:
	* здесь можно просто скопировать содержимое, чтобы в дальнейшем просто внести в них небольшую корректировку по нужному ключу (особенно актуально для токенов авторизации); 
3. изучить содержимое и при необходимости внести в них изменения командой `localStorage.setItem('key', 'value')`.
