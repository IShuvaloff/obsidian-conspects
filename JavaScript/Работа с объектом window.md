#window #ssr

Объект **window** является системным, позволяет управлять сайтом встроенными средствами браузера. 
==Недостатки==:
1. доступен только на клиенте, т.е. не работает в хуках Nuxt/Vue в SSR;
2. в проектах Nuxt к объекту `window` следует обращаться не ранее, чем в хуке `onMounted` (во всех последующих можно).

### Лайфхаки
1. если возникают проблемы с маршрутизатором Nuxt/Vue^[например, если возникла ошибка на главной странице, а на ней находится кнопка с возвратом на главную страницу. По идее ошибка перехода не должна срабатывать в рамках правильно настроенного Nuxt Error Handling, но принцип понятен], можно выполнить **браузерный переход по ссылкам**, минуя Vue Router:
   
	```ts
	    window.history.pushState(null, "/");
	```
	
	Как вариант, можно также использовать такие операции (подмена текущего адреса или переход по обычной ссылке):

2. [[Плавный скролл по экрану]] - использование `windows` в серверном рендеринге (SSR);
3. доступ к информации о текущем сайте - **`window.location`**, содержит в себе поле `origin` (корень сайта), `href` (абсолютная ссылка на текущую страницу) и т.д.

### Обработчики событий
1. установка **обработчика события ресайза** - требуется для тех случаев, когда нужно производить какие-либо операции в зависимости от текущего размера экрана (для перерасчета при изменениях). Подробности см. в проекте "TDS Group", в компоненте `src/modules/materials/components/MaterialCard.vue`:
   
   ```ts
   onMounted(() => {
	    window.addEventListener("resize", setLargePhotoSize);
	});

	onBeforeUnmount(() => {
	    window.removeEventListener("resize", setLargePhotoSize);
	});
	```
   * в проекте Nuxt выставляем обработчик в хуке `onMounted`, тогда как в хуке `onBeforeUnmount` уничтожаем;
   * при каждом изменении размеров экрана^[например, при повороте дисплея на мобильном устройстве] будет вызываться процедура `setLargePhotoSize`);
4. установка **обработчика события скролла экрана** - требуется для тех случаев, когда нужно производить расчеты в пикселях в зависимости от величины прокрутки. Подробности см. в проекте "TDS Group", в компоненте `src/components/layouts/Header.vue`:
   
   ```ts
	onMounted(() => {
	    if (!isMobileOrTablet) window.addEventListener("scroll", handleScroll);
	});
	
	onBeforeUnmount(() => {
	    if (!isMobileOrTablet) window.removeEventListener("scroll", handleScroll);
	});
	```
	* в момент старта скролла происходит срабатывание события и вызов функции `handleScroll`;
