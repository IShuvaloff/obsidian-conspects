#env #env-example

Файл **`.env`** - это скрытый файл, который используется для хранения переменных окружения (переменных среды). Этот файл является секретным, никто, кроме вас, не может получить к нему доступ, и он может быть использован для хранения данных, которые вы хотите сохранить конфиденциальными или скрытыми. Например, можно хранить ключи API из внешних служб или URI базы данных. Вы также можете использовать его для хранения параметров конфигурации.

==Примеры данных== для хранения в `.env`:
1. *хост* (ip-адрес сайта) - чаще всего это `localhost`, т.к. это системный адрес как для компьютеров разработчиков, так и для сервера;
2. *порт* - любое числовое значение, требуется по той причине, что на одном и том же компьютере могут находиться несколько запущенных серверов - каждый на своем порту;
3. *api-адрес с данными для сайта* - адрес сервера, с которого получаем информацию по api-запросам (fetch, axios);
4. *api-адрес с сервисом imgProxy* - адрес прокси-сервера для обработки изображений, обычно должен быть развернут на том же домене, что и сам сайт;
5. *публичный ключ для Captcha* - ключ для работы капчи, без которого проверка на формах невозможна (например, [Yandex SmartCaptcha](https://cloud.yandex.ru/ru/docs/smartcaptcha/operations/get-keys)).

==Доступ к данным== производится через обращение к **`process.env.<...>`** (любой другой идентификатор из файла) либо через аналогичный запрос **`import.meta.env.<...>`**. Доступ к этим данным в Nuxt осуществляется в файле `nuxt.config.ts` в блоках `devServer` и `runtimeConfig` (см. [[Nuxt.js/Конфигурация проекта|Конфигурация проекта]]).

==Особенности==:
1. после изменения данных в файле  требуется пересобрать проект, т.к., несмотря на автоматическую пересборку приложения Nuxt после смены конфигурационных данных, содержимое `.env` читается только единожды после сборки.
