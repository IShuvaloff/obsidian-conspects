#video #ffmpeg

Во время загрузки видео можно не ожидать заполнения контейнера с блоком, а поступить иначе:
1. установить приложение [ffmpeg](https://ffmpeg.org/download.html):
	1. скачать архив .zip для Windows (не tar.7z!);
	2. распаковать архив в папку с утилитами;
	3. добавить в системную переменную PATH адрес папки `/bin` в распакованном архиве;
2. через консоль (см. документацию) извлечь первый кадр нужного видео командой:
   
	```shell
	ffmpeg -i input.mkv -ss 00:00:00 -vframes 1 output.png
	```

3. на контейнер с видео навесить CSS-свойство `aspect-ratio` - ширина будет задаваться шириной экрана, а высота в зависимости от значения этого свойства (рассчитать заранее aspect-ratio у видеоэлемента);
4. полученное в п.2 изображение разместить в директорию проекта и отобразить в контейнере для видео в теге `<video>` в [атрибуте](https://developer.mozilla.org/ru/docs/Web/HTML/Element/video#poster) `poster`:
