#scroll 

Плавное перелистывание страницы к нужному элементу (обычный `scrollBy`/`scrollIntoView` на мобильных устройствах не работает - там скролл происходит в результате скачка к нужному месту^[хотя в проекте Завидово путем установки css-свойства **`html { scrollBehaviour: smooth; }`** удалось добавить плавность даже в Safari]) - использование плагина [**`scroll-animate-to`**](https://web7.pro/14-js-bibliotek-dlya-raboty-so-skrollingom/#:~:text=%D0%BA%20%D1%81%D0%BE%D0%B4%D0%B5%D1%80%D0%B6%D0%B0%D0%BD%D0%B8%D1%8E%20%E2%86%91-,Scroll%20animate%20to,-%D0%94%D0%B0%D0%BD%D0%BD%D0%B0%D1%8F%20%D0%B1%D0%B8%D0%B1%D0%BB%D0%B8%D0%BE%D1%82%D0%B5%D0%BA%D0%B0%20%D0%B2%D0%BE). Установка через `npm i` неудачна, т.к. внутри идет прямое обращение к `windows`, а при серверном рендеринге этого объекта не существует. Поэтому скачиваем файл .js и после некоторых манипуляций можем использовать его в проекте Nuxt:
1. файл для вставки в сервисные файлы проекта - см. в списке файлов, `Файлы/scroll-animate-to.js`;
2. работа с файлом развернута в проекте "TDS Group" на странице "О компании" `src/pages/about.vue`;
3. в файле по умолчанию инициализируется класс-заглушка `ScrollTo`, а затем на клиенте происходит переинициализация его в требуемый класс для осуществления прокрутки:
