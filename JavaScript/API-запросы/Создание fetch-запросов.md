### POST-запросы
Контент - содержимое POST-запроса - заносится обычно в такие поля запросов, как **body** (нативный fetch-запрос), **data** (axios-запрос) и им подобные. 
Типы контента при отправке данных:
1. `'Content-Type': 'application/json'` - по умолчанию, через JSON-формат;
2.  `'Content-Type': 'multipart/form-data'` - при необходимости включить в отправку бинарные данные (фото, файлы и т.д.). При отправке подобных данных требуется объект JS преобразовать в объект FormData:
   
	```js
	const object = {...}
	const formData = new FormData()
	for (const key in object) {
		formData.append(key, obj[key])
	}
	```
