Заголовки запросов прописываются обычно в параметре `header` любого запроса, будто `fetch`-запрос из нативного JS или запрос из плагина `axios`, а также запросы фреймворков, как [[Композаблы Nuxt.js (composables)#Извлечение данных по url-адресу|`useFetch`]]/[[Композаблы Nuxt.js (composables)#Более сложный вариант асинхронной загрузки данных|`useAsyncData`]] из Nuxt. Коды ответов сервера могут зависеть от набора отправляемых заголовков. Ответы сервера также включают в себя заголовки. 

## Общие заголовки
1. `Content-Type` - тип контента - актуален для *POST* и подобных ему запросов, при которых производится отправка данных на сервер. Также возвращается сервером, указывает на тип возвращенных данных;

## Заголовки запроса:
1. `If-None-Match` - отправляет значение ключа уникальности `ETag`, полученный в предыдущем ответе сервера на тот же самый запрос. В случае, если отправленный ключ совпадает с ключом сервера в результате выполнения нового запроса, сервер возвращает ответ **304 Not Modified** вместо 200 (сервер в этом случае должен поддерживать кэширование и условные запросы: заголовок `ETag`). Редко используются, но оптимальны при получении редко изменяемых данных, например, настроек или профиля пользователя. Применяются в получении данных о выполняемых пайпах в GitLab. Поддерживаются только GET/HEAD-запросы. 
2. `If-Modified-Since` - содержит дату последнего изменения ресурса (из кэша). Работает аналогично, если дата последнего обновления из кэша браузера совпадает с таковой в данных на сервере, то возвращается ответ **304 Not Modified** (сервер в этом случае должен поддерживать кэширование и условные запросы: заголовок `Last-Modified`). Частота и условия использования аналогичны предыдущему заголовку. 

## Заголовки ответа
1. `ETag` - заголовок сервера, отправляемый (в случае поддержки сервером такого функционала) ключ уникальности текущего набора данных. Часто в случае, если повторный запрос на сервер, в котором данный ключ передается через заголовок `If-None-Match`, не изменяет результат, сервер возвращает ответ **304 Not Modified**, а response может быть пустым (необязательно). Значение `ETag` удобно хранить в localStorage.
