1. Простейшая **рандомная сортировка списка** - использование `0.5 - Math.random()` в качестве результирующего значения функции. Кроме того, если требуется извлечь определенное количество рандомных элементов, проще написать функцию:
```ts
listFlatRandom(): (arg0: number) => IComplexCard[] {
	return (count: number) => this.listFlat
		.sort((a, b) => 0.5 - Math.random()) // сортировка
		.slice(0, count); // извлечение нужного числа элементов
},
```
