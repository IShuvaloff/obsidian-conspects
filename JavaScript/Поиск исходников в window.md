Если требуется понять, какие функции зарегистрированы в объекте `window` в процессе работы, нужно зайти во вкладку консоли в DevTools, ввести в консоль "window" и нажать Enter. Мы увидим объект `window`:
![[Pasted image 20231221173837.png]]

==В данной задаче нам потребовалось узнать==, как реинициализировать объект Yandex "Поделиться", т.к. после обновления страницы параметры данного объекта сбрасывались либо нарушалась их полнота. Порядок действий:
1. в качестве предисловия: объект был установлен через подключение скрипта с [официального источника](https://yandex.ru/dev/share/), скрипт подключен через композабл Nuxt 3 `useHead`:
   
   ![[Pasted image 20231221175750.png]]
   
2. открыли в консоли объект `window`;
3. нашли нечто похожее на объект Яндекса - свойство `window.Ya`;
4. в данном свойстве нашли объект `window.Ya.share2` - почему так? Потому что класс нашего объекта со ссылками на социальные сети так и называется - `ya-share2`;
5. находим в этом объекте функцию, которая его создает, для этого находим сам скриптовый файл: 
   
   ![[Pasted image 20231221174214.png]]

5. Ctrl + Click по имени файла `share2.js:23` переводит нас во вкладку со скриптом (23 строка) и конкретно к функции инициализации:
   
   ![[Pasted image 20231221174416.png]]

6. данная функция принимает 2 параметра:
	1. контейнер - это объект с `id`, равным `id="ya-share2"`. При создании объекта со ссылками на социальные сети нам требуется задать этому объекту айдишник^[именно по этой причине не очень хорошо дробить объекты со ссылками на соцсети, поскольку им придется давать одинаковый ID, а это запрещено!]:
	   
	   ![[Pasted image 20231221174552.png]]

	2. параметры - чтобы понять, что за параметры, нам следует просмотреть эту функцию дальше;
7. в функции мы можем увидеть вызов другой функции - `createShare`, где убеждаемся, что параметрами является объект, в котором есть свойство реинициализации `reinit`, по умолчанию `false`:
   
   ![[Pasted image 20231221174941.png]]

8. делаем вывод, что для реинициализации объекта со ссылками на соцсети нам нужно вновь вызвать функцию из п.6 и передать в нее ID (созданный в п.6.1) контейнера со ссылками и параметр реинициализации из п.7:
   
   ![[Pasted image 20231221175532.png]]

	* делать это следует внутри интервала, т.к. при загрузке страницы (например, F5 или вставке адреса в адресную строку, из-за чего и начинаются проблемы) скрипт - если он подключался без асинхронности (из-за чего страница будет ждать, пока он загрузится, - может не успеть загрузиться к моменту `onMounted`;
	* выполнять это следует, только проверив, что данная функция существует;
	* выполнять повторы этого интервала следует в хуке `onMounted`;
	* если операция реинициализации была выполнена, следует отключить интервал во избежания постоянных повторов процесса.
