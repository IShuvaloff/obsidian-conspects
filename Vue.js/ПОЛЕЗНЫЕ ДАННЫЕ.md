1. **`$parent`**- компонент-предок. Полезно, когда к нему нужно обратиться и что-то сделать. Пример: кнопка закрытия в модальном окне - при нажатии срабатывает `$parent?.$emit('close')`, т.е. целиком модальное окно, которое было открыто как компонент, возвращает событие `close`;
2. **Глубокое клонирование в JS** - использование встроенной функции ***structuredClone(object)*** - в качестве объекта следует использовать ==только объект== (не массивы!), которые могут в свою очередь содержать другие объекты, массивы и примитивные типы данных. Кроме того, в параметр нельзя передавать *Proxy* и *ref*/*reactive*, для предотвращения ошибок следует проверить тип объекта и при необходимости использовать преобразование ссылочных данных (см. п.3 далее);
3. **Работа с ссылочными данными** - существует 3 вида ссылок:
	1. *не примитивные типы данных* - объекты - передаются по умолчанию в виде ссылок, т.е. изменения объекта в одном месте проекта ведет к его изменению в других местах;
	2. *прокси-объекты* - объекты, которые создаются в фреймворке Vue 3 для использования в реактивности - они оборачивают другие данные (в т.ч. примитивные) и позволяют движку Vue следить за состоянием этих данных. 
		1. Прокси объект при обычной печати выглядит как *`Proxy(...)`*. При обращении к ним в вычислениях он сразу выдает нужные данные, но в некоторых случаях так делать нельзя (см. далее);
		2. чтобы прокси-объект напрямую преобразовать в статический (обычный) объект, требуется использовать функцию **toRaw**: `simpleData = toRaw(proxyObject);`;
		3. ==ВАЖНО==: в *хранилище Pinia* также все свойства состояния (state) хранятся также в виде прокси-объектов!
	3. *объекты, созданные в рамках Vue Composition API* путем оборачивания в функции *ref* и *reactive*, которые возвращают новый объект (см. [[Composition API|здесь]]). Чтобы получить фактическое значение объекта внутри, требуется использовать поле этого объекта **value**:  `data = refObject.value`;
	4. одновременное преобразование реактивных прокси-данных - см. в [[Композаблы Nuxt.js (composables)#^0704a2|извлечение данных по url-адресу]];

6. **Передача свойств в CSS-переменные**:
	1. создать ref-свойство либо computed-свойство^[т.к. в первую очередь передачу свойств в CSS-код используем в случаях, когда этот CSS-параметр должен изменяться в процессе использования сайта] в скрипте:
		```ts
		const propHeight = computed(() => 200);
		```
	2. в шаблоне в требуемый тег добавить атрибут `:style` с передачей в него значения свойства:
		```html
		<div class="block" :style="`--block-height:${propHeight}px;`"></div>
		```
	3. в стилях назначить стиль тегу с использованием CSS-переменной:
		```css
		.block {
			height: var(--block-height);
		}
		```

8. ==[Динамическая привязка классов](https://v3.ru.vuejs.org/ru/guide/class-and-style.html#%D1%80%D0%B0%D0%B1%D0%BE%D1%82%D0%B0-%D1%81-%D0%BA%D0%BB%D0%B0%D1%81%D1%81%D0%B0%D0%BC%D0%B8-%D0%B8-%D1%81%D1%82%D0%B8%D0%BB%D1%8F%D0%BC%D0%B8)== через **`:class`**:
   
	```ts
	const className = 'newClass';
	const isShowClass = false;
	```
	1. использование переменной с наименованием класса:
		```html
		<div :class="className" />
		```
	2. использование класса в зависимости от условия:
		```html
		<div :class="{ 'p-12': isShowClass }" />
		<div :class="{ className: isShowClass }" />
		```
	3. комбинирование двух вариантов:
		```html
		<div :class="[ className, { 'p-12': isShowClass } ]"/>
		```
