[Создание проекта](https://cli.vuejs.org/ru/guide/creating-a-project.html#%D1%81%D0%BE%D0%B7%D0%B4%D0%B0%D0%BD%D0%B8%D0%B5-%D0%BF%D1%80%D0%BE%D0%B5%D0%BA%D1%82%D0%B0) производится вызовом команды:
```npm
vue create <project-name>
```
==Процесс создания==:
1. выбрать настройки по умолчанию;
2. выбрать настройки *вручную* с возможностью подключения дополнительных плагинов:
   ![[Pasted image 20231024223045.png]]
3. есть возможность после выбора вариантов настройки *сохранить их в шаблон*; шаблоны сохраняются в файле `.vuerc` в домашнем каталоге пользователя ОС;
4. в версии Vue 3 осталась возможность Ш (например `webpack`) с помощью команды:
	```npm
	vue init <template-name> <project-name>
	```
5. команды запуска приложения, которые добавятся автоматически в файл `package.json`:
	```json
	{
		"scripts": {
			"serve": "vue-cli-service serve",
			"build": "vue-cli-service build"
		}
	}
	```
	1. для запуска проекта используется сервис vue-cli;
	2. serve - запуск в режиме разработки;
	3. build - сборка финальной версии сайта.
