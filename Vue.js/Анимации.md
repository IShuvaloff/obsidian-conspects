## Анимации горизонтального пролистывания
1. инициирование типа анимации:
   
   ```ts 
   // Начальное направление - движение вправо
   const transitionName = ref("slide-forward"); 
   ```
   
2. задание типа последующего переключения в зависимости от условий:
   
	```ts
	transitionName.value = directionRight ? "slide-forward" : "slide-backward";
	```

3. создание HTML-кода анимации:
	1. создание анимационного блока `transition` с указанием имени;   
	2. размещение внутри контейнера с переключаемыми блоками (например, вкладками) с указанием ключа для правильной отрисовки (в нашем случае `step` - номер вкладки);
	3. размещение переключаемых блоков внутри через директиву `v-if`:
   
		```html
		<transition :name="transitionName" mode="out-in">
		   <div :key="step" class="tab">
			   <div v-if="step === 1">...</div>
			   <div v-if="step === 2">...</div>
		   </div>
		</transition>
		```

4. добавление стилей анимации:
   
	```css
	/* Общие стили для анимации */
	.tab {
	    transition: transform 0.3s ease, opacity 0.3s ease;
	}
	
	/* Анимация перехода вперед */
	.slide-forward-enter-active {
	    transform: translateX(100%);
	}
	.slide-forward-enter-to {
	    transform: translateX(0);
	    opacity: 1;
	}
	.slide-forward-leave-active {
	    transform: translateX(-100%);
	    opacity: 0;
	}
	
	/* Анимация перехода назад */
	.slide-backward-enter-active {
	    transform: translateX(-100%);
	}
	.slide-backward-enter-to {
	    transform: translateX(0);
	    opacity: 1;
	}
	.slide-backward-leave-active {
	    transform: translateX(100%);
	    opacity: 0;
	}
	```

## ВАЖНЫЕ МОМЕНТЫ

1. при использовании форм внутри переключаемых блоков (напр., вкладок) следует с осторожностью выставлять фокус на элементы, т.к. это вызывает перерисовку элемента. Проблема: **может дергаться экран при перелистывании вкладок**. Варианты решения:
	* снять автофокус с инпута, если он необязателен;
	* установить фокус программно: `inputElement.value.focus({ preventScroll: true });` (*не проверено*);
	* использовать отложенную фокусировку: в `onMounted` сфокусировать элемент через `setTimeout`; (*не проверено*. Плюс ==наверное нужно выставлять фокус не ранее, чем завершится анимация переключения==):
	  
		```ts
		onMounted(() => { 
			if (props.focused) { 
				setTimeout(() => { 
					inputElement.value.focus({ preventScroll: true }); 
				}, 100); 
			}
		});
		```
	  
	* фокусировать инпут только при вхождении его в область видимости экрана (*не проверено*):
	  
	  ```ts
	  onMounted(() => { 
		  if (props.focused) { 
			  const rect = inputElement.value.getBoundingClientRect(); 
			  if (rect.top >= 0 && rect.bottom <= window.innerHeight) { 
				  inputElement.value.focus({ preventScroll: true }); 
			  } 
		  } 
	  });
	  ```
	  
	* управлять фокусом вручную через пользовательские события (*не проверено*):

		```ts
		const inputElement = ref(null); 
		const focusInput = () => { 
			inputElement.value.focus({ preventScroll: true }); 
		}; 
		```
		
		```html
		<template> 
			<input ref="inputElement" type="text" /> 
			<button @click="focusInput">Фокусировать</button> 
		</template>
		```
