#border-radius #overflow #clip-path

Способы:
1. через `border-radius` и `overflow-hidden` - совокупное применение этих свойств позволяет округлить блок по нужному радиусу (50% для полного округления) и сокрытия частей блоков, выступающих за границы этого округления. Недостатки:
	1. непредсказуемое поведение в долго загружающихся блоках, например, при использовании ImageProxy: фон и границы контейнера отрисовываются, пока идет обработка исходной картинки, а потом картинка показывается вылезающей за края;
2. через `clip-path` контейнера. Подробнее изучить можно [здесь](https://www.8host.com/blog/obrezka-izobrazhenij-v-css-s-pomoshhyu-clip-path/). Позволяет обрезать блок одним из свойств SVG-изображения:
	1. округление блока через команду `circle`:
	   
		```css
		.block {
			clip-path: circle(50% at 50% 50%);
		}
		```

		* первый параметр 50% - радиус обрезки от центра (преобразовать квадрат в круг или прямоугольник в эллипс);
		* разделитель `at` - указывает на координаты центра, вокруг которого нужно производить обрезку;
		* 50% 50% - координаты центра по осям X и Y;
