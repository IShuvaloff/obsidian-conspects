#safari

Браузер Safari может неправильно рендерить страницу, если есть размеры элементов не ограничены или не указаны явно. Особенности решения проблем:
1. Установка `w-full`/`h-full` в тех компонентах, где ==для родителя не указаны явные размеры==. В этом случае нужно:
	* либо убрать атрибуты 100%-й высоты/ширины для вложенных компонентов и/или добавить минимальную высоту/ширину;
	* либо у родителей выставить `min-w-...`/`min-h-...`;
2. ==проблемы со сдвигом рядов grid вниз/вверх при изменении масштабов экрана==. Варианты решения аналогичны:
	* либо убрать атрибуты 100% высоты для элементов грида и/или выставить минимальную высоту элемента;
	* либо для грида выставить `grid-auto-rows: 1fr`, что позволит выровнять высоту каждого ряда грида, равную максимальной высоте из всех вложенных элементов;
	* либо выставить у грида атрибут `items-start`, что запретит вложенным элементам съезжать вниз в случае, если ряды будут рендериться неправильно: все элементы будут выравниваться по верхнему краю ряда и, возможно, это исправит проблему наползания последнего ряда грида на более нижние элементы;
	* также можно попробовать выставить в качестве размеров элементов свойство `aspect-ratio`, что также зафиксирует размеры элементов, т.к. ширина ячеек чаще всего высчитывается корректно, а высота будет зависеть от ширины.
