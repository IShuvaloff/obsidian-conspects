#margin

1. Использование комбинированных тегов с символом **`+`** - позволяет применить указанный стиль только к каждому идущему сразу следом элементу, следовательно, к самому первому `p` из кода ниже этот стиль не применяется - в этом случае между абзацами внутри большого блока будут гэпы, как в гриде:
	```css
	p + p {
		margin-top: 20px;
	}
	```
1. Автоматическое продление отступа с прижатием блока к одному из краев - использование свойства `margin-...: auto`. Позволяет прижать элемент к противоположному от заданного свойства краю, например: `margin-top: auto` прижмет блок к нижней части родителя;
2. Аналог предыдущего пункта - растягивание блока с содержимым до максимального размера в пределах родителя, если **родитель - flex-элемент**, - использование `flex-grow: 1` для текущего блока. По умолчанию данное свойство равно 0;
