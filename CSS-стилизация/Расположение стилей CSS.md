
==Стили CSS применяются в следующем порядке==:
1. инлайновые стили - то, что прописано прямо в HTML, в т.ч. с использованием стилей Tailwind и других библиотек;
2. стили из подключаемых файлов - чем позже подключен файловых стиль (в атрибуте class в теге html), тем больший приоритет он имеет (см. также приоритеты стилей).

==Примеры косяков==:
* если для одного элемента выставлен инлайновый стиль, а следом проставлен файловый стиль, то сперва визуально будет применен инлайновый стиль, и лишь затем файловый - это может привести к скачкам и изменениям в стилях для элемента, например, изображение будет сперва по инлайновому стилю `h-full` растягиваться до полной высоты, а затем по файловому стилю с максимальной высотой ужиматься до нужного значения;
* для слайдеров бывает сложно настроить внутренние контейнеры - стили могут не применяться. В этом случае следует либо использовать `!important`, что не очень желательно, либо прописывать длинную цепочку стилей для повышения приоритета кастомизируемых стилей, например:
