Для задач, где требуется добавить скролл по горизонтали для мелких экранов, притом что у элементов внутри контейнера есть минимальная ширина (вследствие чего скролл и требуется), достаточно просто выставить свойства `overflow-x-auto` у контейнера (см. пример далее). В этом случае на компьютере при уменьшении ширины экрана мы увидим стандартный "некрасивый" скролл, но *==нет смысла его убирать==*, т.к. на мобильных экранах он будет заменен системным "красивым":

![[Pasted image 20240123110821.png|300]] ![[Pasted image 20240123111017.png|315]]

CSS-[свойства](https://habr.com/ru/articles/498456/):
1. **`scroll-snap-type`** - применяется для контейнера с элементами, у которого выставлено свойство `overflow-auto` или `overflow-scroll`. Обозначает направление прокрутки (*x*/*y*) и его особенности (*mandatory*/*proximity*). Пример:
   
   ![[Pasted image 20240117165715.png|300]]
   
2. **`scroll-snap-align`** - применяется для элементов в контейнере и определяет, к какому краю элемента будет производиться привязка контейнера. Проще говоря, выровняется ли элемент посреди контейнера (*center*), прилипнет к его левому краю (*start*) или к правому краю (*end*). Пример:
   
   ![[Pasted image 20240117165930.png|260]]

### Готовый компонент линейки карточек
Готовый компонент линейки карточек, которые скроллятся при уменьшении минимальной величины (см. проект "Завидово", компонент CommonXScrollBlock), применяется в т.ч. в *карточке Недвижимости - "Другие проекты"*:
1. **создана карточка `Card.vue`**, несколько штук которых будут включены в прокручиваемую линейку. Необходимо жестко задать ширину/мин. ширину карточки, т.к. от этого будет зависеть появление скролла либо бесконечное сжатие карточки в линейке:
	   
   ![[Pasted image 20240208155654.png]]
   
   * задается требуемая высота изображения для разных экранов, а также ширина 100%, чтобы заполнить содержащий изображение контейнер;
   * задается ширина контейнера с изображением для разных экранов, при этом выставляется максимальная ширина 100%, чтобы контейнер, который содержится в другом контейнере (например, в столбце сетки `grid-cols-`), не вылезал за пределы его границ;
	   
2. **создан компонент `XScrollBlock`** - блок, прокручиваемый по горизонтали. Включает в себя все необходимые настройки для совершения прокрутки и выравнивания внутренних элементов (`start`/`center`/`end`, см. `scroll-snap-align` выше), и слот для заполнения требуемыми карточками/фотографиями:
   
   ![[Pasted image 20240208160520.png]]
   * кроме того, средствами JS проставлены нужные стили выравнивания для всех входящих в контейнер элементов - другим путем (через `:deep(...)`) в стилях это сделать невозможно;
   
3. **компонент используется на странице проекта** и содержит в себе список карточек с описанием различных проектов:
   
   ![[Pasted image 20240208160946.png]]
   
   * используемый компонент по умолчанию будет являться линейкой карточек, которая будет прокручиваться по горизонтали в случае, если не вмещается в контейнер;
   * заданы дополнительные настройки компонента, чтобы превратить его из линейки в сетку Grid при достижении определенного размера экрана.
