При необходимости, например, затемнить блок, можно наложить на него специальный фильтр^[в отличие от фильтров [[Фоны и фильтры элементов|здесь]] прозрачность самого блока не меняется, а регулируется прозрачность наложенных поверх блоков]. Делается это так:
1. для блока - например, изображения - создается псевдоэлемент **`::after`**, внутри которого задается пустой контент, абсолютное позиционирование с выравниванием по всем 4-м краям родителя;
2. для псевдоэлемента выставляется фон, например, цвет или градиент с определенным уровнем прозрачности (чем выше `opacity`, тем затемненней изображение родителя под ним):
   
   ![[Pasted image 20240219173615.png]]

4. при наведении мышки на блок (используется пседовкласс `:hover`) прозрачность выставляется в максимальную (`opacity: 0`), и блок виден полностью во всей полноте красок;
5. если требуется сфокусировать объект, который не является фокусируемым по умолчанию (кнопка, инпут, ссылка и т.д.), достаточно присвоить блоку родителя атрибут `tabindex="0"`^[для отмены фокусировки любого элемента нужно выставить значение `tabindex="-1"`, либо удалить атрибут средствами JS через `block.setAttribute("tabindex", "-1")`], и для псевдокласса `:focus` также выставить нулевую прозрачность;
6. если требуется плавное затемнение, используем транзишн свойства прозрачности, т.к. транзишн не работает с градиентами.
