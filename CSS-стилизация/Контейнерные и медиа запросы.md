## Контейнерные запросы
[**Контейнерные запросы**](https://developer.mozilla.org/en-US/docs/Web/CSS/CSS_containment/Container_queries) - позволяют изменять стилистику содержимого в зависимости от ширины контейнера^[аналогично медиа-запросам с настройками контента в зависимости от ширины целой страницы].
Управление запросами:
1. задать настройки контейнера:
	1. тип контейнера: `container-type: inline-size;`;
	2. имя контейнера (*опционально*): `container-name: sidebar;`;
	3. сокращенный вариант: `container: sidebar / inline-size;`;
2. выставить настройки по умолчанию для элементов в контейнере;
3. добавить контейнерные запросы:
	1. при *отсутствии имени* контейнера - относится ко всем элементам, входящим во все безымянные контейнеры:
	   
	   ```css
	   @container (max-width: 500px) { /* настройки стилей содержимого */ }
		```
	   
	2. при *наличии имени* контейнера - настройки будут применяться к элементам только этого контейнера:
	   
	   ```css
	   @container sidebar (max-width: 500px) { ... }
		```
	   
1. единицы измерения для элементов контейнера: 
	- `cqw`: 1 % ширины контейнера запроса;
	- `cqh`: 1% высоты контейнера запроса;
	- `cqi`: 1 % от встроенного размера контейнера запроса;
	- `cqb`: 1 % от размера блока контейнера запроса;
	- `cqmin`: Меньшее значение либо `cqi`или`cqb`;
	- `cqmax`: большее значение либо `cqi`или`cqb`;
1. **альтернатива контейнерным запросам** в случае отсутствия поддержки в некоторых браузерах - использование `grid` и/или `flex` с настройкой позиционирования в зависимости от ширины экрана *с использованием медиа-запросов*.
