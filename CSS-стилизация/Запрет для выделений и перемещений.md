#user-select #draggable

Несколько CSS-свойств для запрета выполнения данных операций:
1. запрет перетягивания данных - выполняется для изображений^[т.к. по умолчанию можно перетягивать изображения - появляется соответствующий элемент на экране] - атрибут тега **`<img draggable="false"`**;
2. запрет на выделения инлайновых объектов в контейнере (как, например, svg-изображение) - css-свойство **`user-select: none`**;
