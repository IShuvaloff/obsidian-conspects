#backdrop-filter #filter #opacity #background

Работа с элементом включает в себя:
* цвет фона;
* прозрачность фона;
* фильтры фона;
* фильтры всего элемента;
* прозрачность всего элемента.

### Цвет и прозрачность фона

Задается свойством `background-color`. Для установки цвета используется формат RGB, для добавления прозрачности - формат RGBA:

```css
.element-1 {
	background-color: #FFFFFF; /* полностью непрозрачный белый цвет */
}
.element-2 {
	background-color: rgba(255, 255, 255, 0.7); /* прозрачность 70% */
}
```

При использовании ==Tailwind== прозрачность фона настраивается отдельно классом `bg-opacity-...`.

### Фильтры фона

Задаются свойством [`backdrop-filter`](https://developer.mozilla.org/en-US/docs/Web/CSS/backdrop-filter), позволяют установить размытие, инверсию цвета, сепию и т.д., но **только для фона**, *содержимое элемента не затрагивается*:

```css
.element {
	backdrop-filter: blur(6px); /* добавляется размытие только фону */
}
```

### Прозрачность целого элемента

Задается свойством `opacity`, значение от 0 до1. Прозрачность применяется ко всему элементу, включая фон:

```css
.element {
	opacity: 0.5; /* сделать полупрозрачным целый элемент */
}
```

==**ЗАМЕЧАНИЕ**==: нельзя совместно использовать `opacity` и `backdrop-filter` - при фильтре `blur` и добавлении прозрачности *фильтр теряет свои качества* (размытие пропадает). 

### Фильтры целого элемента

Задаются свойством `filter`, значения аналогичные свойству `backdrop-filter`. 

### Смешение цветов (новая фишка CSS)

Позволяет сделать примесь нового цвета (включая transparent) к исходному, с нужной интенсивностью. Используется CSS-функция `color-mix(in oklch, red, green 50%)`:
- *первый параметр* - цветовое пространство. Сейчас наиболее современным считается oklch, т.к. поддерживает гораздо более широкий (в яркую сторону) диапазон цветов, чем srgb. Варианты: `in [srgb | hsl | lab | lch | oklab | oklch]` и др. 
- *второй параметр* - исходный цвет, может также указываться с процентами, по умолчанию - разница между 100% и значением второго цвета;
- третий параметр - примешиваемый цвет, может быть и без процентов, по умолчанию - разница между 100% и значением первого цвета.
