#video

Особенности:
1. [Кодировка видео для работы в браузерах Safari](https://developer.apple.com/documentation/webkit/delivering_video_content_for_safari/) - требуется кодировка H.264-encoded MP4 файлов;
2. См. *проект Завидово* - компонент для просмотра видео **UiBackgroundVideo**;
3. Если мы вставляем тег `<video>` и нужно активировать параметр `autoplay`, следует учитывать:
	1. Google предоставляет право автопросмотра только проверенным источникам, в противном случае автопросмотр доступен только с заглушенным звуком;
	2. Если в источнике просмотра не уверены, следует== для работы автозапуска выставить параметр заглушки звука `muted`==!
