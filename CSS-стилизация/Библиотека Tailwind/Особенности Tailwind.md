
==Особенности использования библиотеки Tailwind в PostCSS==:
1. применение стиля Tailwind внутри блока PostCSS - через ключевое слово **`@apply`** - в данном примере ко всем классам `class-name` будет применен стиль `margin-bottom: 20px`:
	```css
	.class-name {
		@apply md-5;
	}
	```
	ВАЖНОЕ ЗАМЕЧАНИЕ: если мы используем в кастомных стилях (`<style></style>`) файла директиву `@apply`, пытаясь применить стиль из Tailwind, то даже если этот стиль *мы переопределили в другом кастомном стиле*, применятся свойства этого стиля только из Tailwind!
2. написание динамических стилей в атрибуте `class="..."` допускается только с использованием **полных имен классов**, т.е.:
