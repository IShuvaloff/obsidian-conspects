#tailwind-config

Расширение, переопределение стилей, кастомизация имеющихся, создание новых классов см. [здесь](https://tailwindcss.com/docs/theme).

==Пример кастомизации==:

![[Pasted image 20231220142054.png]]

1. ключевое слово `extend` позволяет не заменить полностью стили, как это сделано, например, для `fontFamily`, а добавить к имеющимся стилям новые;
2. `colors` позволяет переопределить цвета - в данном случае мы заранее создаем в проекте нужные нам цвета с их названиями - впоследствии для использования этих цветов нужно будет указать стиль с указанным именем применительно к префиксу того, к чему этот цвет относится, например, `bg-bg_gray_001` (окрашивание фона) или `text-text_002` (цвет текста);
3. `fontSize` позволяет добавить стили из 4-х настроек для каждого - размер шрифта (как первый параметр массива и объект с расстоянием между символами, размером шрифта и высотой строки). Т.к. во многих случаях требуется указать также медиазапрос, если шрифт отличается для разных экранов, то, возможно, проще сделать эту работу через добавление кастомных стилей. Делается это двумя способами:
	* В файле `src/assets/css/main.css`^[но в этом случае на созданный шрифт не будет работать подсказка (хинт) при наведении в html-шаблонах, тогда как в первом случае все работало бы]:
   
	   ![[Pasted image 20231220142345.png|200]]

		Теперь если прописать стиль `text-48_regular` для первого варианта, описанные свойства будут применены к тексту.
	* В файле конфигурации **tailwind.config.ts**. В этом случае требуется для каждого класса шрифта указать массив, состоящий из строки с размером шрифта и объекта с тремя полями - *высота строки*, *расстояние между буквами* и *толщина шрифта*:
	  
	  ![[Pasted image 20240711161518.png]]
   
4. `fontFamily` указан за пределами `extend`, поэтому он не расширит семейства шрифтов в проекте, а полностью их заменит. В указанном случае созданы 2 семейства шрифтов, каждый из которых содержит список шрифтов, заменяющих друг друга в указанном порядке в массиве. Теперь если прописать стиль `font-nanito` в тегах, содержимому тега будет назначено семейство шрифтов `font-family: "Nanito Sans", arial, sans-serif`;
	* настройка [шрифта по умолчанию](https://tailwindcss.com/docs/font-family#customizing-the-default-font) делается двумя способами, либо переопределением системного семейства шрифтов:
	  
	  ![[Pasted image 20231220143520.png|350]]
	  
	  либо добавлением базового стиля явно в файле `src/assets/css/main.css`:
	  
	  ![[Pasted image 20231220143614.png|350]] ![[Pasted image 20231220152858.png|200]]
	  
  
1. `screens` позволяет заменить (вне `extend`) или дополнить список размеров экрана для создания медиа-запросов. Применение данных свойств таково, что мы указываем стиль, затем двоеточие и после него требуемый класс стиля (например, цвета шрифта для экранов шириной от 1600px: `2xl:text-text_002`);
2. **Добавление новых кастомных классов** - производится путем расширение слоев (layers) в исходном css-файле. Например, аналогично п.5, где в базовом слое переопределялся дефолтный шрифт, можно добавить специальные классы в слое `@layer utilities {...}` и использовать их впоследствии в html-блоках компонентов:
