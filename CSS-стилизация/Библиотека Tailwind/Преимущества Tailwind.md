
==Преимущества использования библиотеки==:
1. можно создавать как **переменные**, так и **миксины**, и, следовательно, использовать их в написании своих стилей;
2. нет существенной необходимости использовать препроцессоры, т.к. их функционал заменен функциональностью Tailwind;
3. удобно использовать в сочетании с псевдоязыком PostCSS, т.к. префиксы - единственное, чего не хватает Tailwind, а PostCSS позволяет писать полноценные стили с вложенными элементами с синтаксисом, аналогичным SCSS;
4. хорошо поддерживается платформой VSCode, можно установить плагин "Tailwind CSS IntelliSense"^[*id* в маркетплейсе расширений - bradlc.vscode-tailwindcss] - как и любой **IntelliSense-плагин** позволит проводить *сканирование кода, вывод подсказок и прочих хинтов, помогать в автозавершении тегов, организует корректную подсветку* и т.д.;
