#hover #focus #active #disabled

Порядок псевдоклассов такой, чтобы не нарушался приоритет одних состояний над другими: более мягкие выше, более жесткие ниже. 

```css
.btn { ... }            /* базовый стиль */
.btn:hover { ... }      /* цвет при наведении */
.btn:focus { ... }      /* outline / подсветка при фокусе */
.btn:active { ... }     /* при удержании клика */
.btn:disabled { ... }   /* когда отключена */
```

В данном случае подразумевается:
1. **дефолтный** класс самый первый (не подвержен никаким изменениям);
2. **наведение** мыши изменяет стиль;
3. **фокус** - должен выделять как-то кнопку, поэтому чаще всего перекрывает наведение;
4. **активность** - нажатие кнопки включает в себя наведение + фокус;
5. **отключение** - ни одно из предыдущих изменений не должно себя выдавать (блок недоступен).
